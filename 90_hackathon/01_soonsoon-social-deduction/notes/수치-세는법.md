# 보고서 수치 — 어떻게 세는가

> **왜 이 문서가 있나:** 대표님께 드리는 보고서(`docs/soonsoon-hackathon.html`)에
> 커밋 수·줄 수 같은 **수치 주장**이 들어간다. 그런데 **세는 법이 어디에도 없어서**
> 2026-08-27 에 「지금 값과 다른데 어떻게 셌는지를 몰라 못 고치는」 상황이 났다.
> 커밋 로그를 뒤져서야 방법을 복원했다.
>
> ⚠ **세는 법을 안 적으면 그 숫자는 다음 사람이 못 고친다.** 여기 적어 둔다.

## 명령

```bash
cd 90_hackathon/01_soonsoon-social-deduction
```

### 커밋 수

```bash
git -C ../../ log --oneline -- 90_hackathon/ | wc -l
```

⚠ **폴더 개명 전후를 합쳐서 센다.** 개명 후 경로만 세면 절반 이하로 나온다
(2026-08-27 기준 155). `90_hackathon/` 로 세면 개명 전 커밋까지 잡힌다.

### 소스 줄 수 — **회사 엔진 벤더링분 제외**

```bash
소스() { find "$1" -type f \( -name "*.js" -o -name "*.mjs" \) | grep -v vendor | grep -v _local; }
소스 proto/src   | xargs wc -l | tail -1      # src
소스 proto/tools | xargs wc -l | tail -1      # tools
ls proto/*.html  | xargs wc -l | tail -1      # 화면
ls proto/*.mjs   | grep -v mirror | xargs wc -l | tail -1   # 서버
소스 proto/api   | xargs wc -l | tail -1      # 서버(배포용)
```

⛔ **`vendor/` 는 회사 코드다.** 우리가 쓴 줄로 세면 거짓이 된다.
⛔ `_local/` 도 뺀다 — 커밋되지 않는 개인 사본이다.
⚠ `mirror.mjs` 는 벤더링을 내려받는 스크립트라 「서버」에 안 넣는다.
