## 왜 폴더가 둘인가 — `docs/` 와 `notes/`

`4097a02` (2026-08-26) 에서 **의도적으로 갈랐다.**

```
docs/    밖으로 나가는 것   — 보고서 · 발표물 · 외부가 읽는 문서
notes/   우리 기록          — 회고 · 작업규칙 · 실패 기록 · 로그
```

경계의 정본은 **`docs/README.md`**(「문서 지도 — 무엇을 어디에 적는가」)다.
새 문서를 만들기 전에 그 표를 본다.

```
