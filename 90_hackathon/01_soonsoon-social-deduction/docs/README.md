# 문서 지도 — 무엇을 어디에 적는가

> 문서가 늘어나면서 같은 내용이 여러 곳에 흩어지기 시작했다. **기록 전에 이 표를 본다.**
> 새 사실을 알게 되면 **한 곳에만** 적고, 다른 문서에서는 링크로 가리킨다(SSoT).

## 폴더가 둘이다 — `docs/` 와 `notes/` (2026-08-26)

**밖에서 보는 것과 우리끼리 보는 것을 갈랐다.** 전에는 22개가 `docs/` 에 섞여 있어,
회사에 낼 보고서와 우리 작업 메모가 같은 목록에 나란히 있었다.

| 폴더 | 무엇 | 누가 보나 |
|---|---|---|
| **`docs/`** | **밖으로 나가는 것만** — 통합 보고서(`soonsoon-hackathon.html`) · 그 그림(`img/`) · 공개 기술문서(`tutorial.md`) · 이 지도 | 회사·대표님·외부 개발자 |
| **`notes/`** | **우리 작업 기록** — 함정·인계·기획·이력·설계안 18개 + `logs/` | 팀과 AI 세션 |

⛔ **`docs/soonsoon-hackathon.html` 의 주소는 바꾸지 않는다.** 이미 팀원들에게 보냈고
문서 여러 곳에 박혀 있다. 그래서 보고서는 두고 **내부 문서만 밖으로 뺐다.**

⚠ 문서를 옮기면 링크가 **조용히** 죽는다. `node proto/tools/check-links.mjs` 로
전수 확인한다(옮기기 전 29개·0깨짐 → 옮긴 뒤 29개·0깨짐으로 맞췄다).
