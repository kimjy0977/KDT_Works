# 마피아 판 — 개선 정밀 분석 (2026-08-24)

> 대상 = `proto/mafia.html` + `src/mafia/**` + 공유 부품(`groupchat.js`·`votescreen.js`).
> **코드를 실제로 읽고, 재는 것은 실제로 재서** 적었다. 추정은 그렇게 표시했다.
> 규모: 마피아 관련 소스 **3,384줄**.

## 요약 — 고칠 순서

| # | 무엇 | 왜 지금 | 크기 |
|---|---|---|---|
| **1** | 유령이 산 사람 토론에 말할 수 있다 | **게임 규칙이 깨진다** | 작음 |
| **2** | 사람이 AI 표를 다 보고 마지막에 투표 | 설계 의도와 코드가 어긋남 | 작음 |
| **3** | 게임의 재시도가 우리가 「나쁘다」고 측정한 방식 | 투표가 통째로 무효화될 수 있다 | 작음 |
| **4** | 마피아 2명일 때 항상 같은 사람이 죽인다 | 한 명이 사실상 무적 | 작음 |

## 1. ⭐⭐ 유령이 산 사람들의 토론에 말할 수 있다 — **규칙 위반**

**확인:** `src/groupchat.js` 에 `dead` 가드가 **한 줄도 없다**(`grep -n dead` → 0건).

입력칸을 잠그는 곳은 딱 하나인데, 그 조건이 **게임 시작 시 고른 관전 모드**다.

```js
const 관전 = state.mode === "watch";     // ← 시작할 때 한 번 정해진다
if (관전) { form.hidden = true; input.disabled = send.disabled = true; }
```

**게임 도중에 죽는 경우는 여기 안 걸린다.** 처형·살해로 유령이 된 플레이어는
입력칸이 그대로 열려 있고, 친 말이 **공개 대화록에 들어간다**:

```js
transcript.push({ who: player.name, text: t, 사람: true });
```

→ 살아있는 AI 들이 **죽은 사람의 말을 읽고 반응**한다. 마피아에서 유령은 침묵해야 한다.

**고치는 법:** 창을 열 때마다 사망 여부로 잠근다(시작 시 한 번이 아니라).
`round.js` 는 이미 `player.dead` 를 알고 있으므로 `open()` 에 넘기면 된다.

---

## 2. ⭐⭐ 사람이 AI 표를 **전부 보고 나서** 투표한다

주석은 *"10초. 대화 없이 **모두 동시에**"* 라고 적혀 있는데 코드는 순차다.

```js
const { 표, 기록 } = await groupChat.지목받기(후보, …, 지목제한);   // ① AI 5명이 다 낸다
…
if (player.isPlayer && !player.dead) {
  내표 = await 내표받기(후보);                                      // ② 그다음에 내가 낸다
```

플레이어는 **누가 누구를 찍었는지 다 본 뒤**, **시간 제한도 없이** 고른다.
표가 3:1 로 몰린 걸 보고 얹기만 하면 되므로 지목 단계의 긴장이 사라진다.

**고치는 법:** 판을 띄우는 즉시 플레이어 선택도 함께 열고, 같은 10초 안에 받는다.
못 고르면 기권 처리(이미 기권 규칙이 있다).

---

## 3. ⭐⭐ 게임의 재시도가 **우리가 「나쁘다」고 측정한 방식**이다

같은 프로젝트 안에서 두 곳이 다르다.

| | 재시도 | 실측 최종 실패율 |
|---|---|---|
| `tools/eval.mjs` | 429면 **2초 × 시도 횟수**, 최대 3회 | **1.0%** |
| `src/groupchat.js` (**게임**) | **400ms 고정, 1회** | **24.8%** |

```js
async function 요청(name, 지시 = "") {
  const r = await 요청1(name, 지시);
  if (r.ok && r.line) return r;
  await 잠깐(400);           // ← 429 에는 소용없다고 이미 쟀다
  return 요청1(name, 지시);
}
```

**측정기만 고치고 게임은 안 고쳤다.** 그런데 429 가 제일 잘 나는 지점이 하필 **투표**다 —
`지목받기` 가 NPC 전원에게 **동시에** 쏘고, 근거 재요청까지 겹치면 순간 최대 10건이다.

**결과가 조용히 나쁘다:** 429 → 그 NPC 기권 → 기권이 지목보다 많으면
**아무도 처형되지 않는다.** 플레이어에겐 "AI 들이 결정을 못 했다"로 보인다. 버그로 안 보인다.

**고치는 법:** `eval.mjs` 의 `부르기()` 를 공유 부품으로 올려 양쪽이 같이 쓴다.
(작업규칙 **N-4** 가 "측정기는 게임과 같은 부품을 써야 한다"인데, **고침이 한 방향으로만 흘렀다.**)

---

## 4. ⭐ 마피아가 2명이어도 **항상 같은 사람이 죽인다**

```js
const 범인 = 마피아들[0];       // 매 밤 동일
```

목격은 살해 지점 근처에서 자던 사람이 **범인 이름을 그대로** 기록한다.
→ **마피아들[1] 은 영원히 목격되지 않는다.** 8인 이상 판(마피아 2명)에서
둘 중 하나는 목격 증거로는 절대 잡히지 않는 셈이다.

**고치는 법:** 밤마다 실행자를 번갈아 고른다. 한 줄이면 된다.

> 덤: `마피아수()` 의 `if (인원 <= 4) return 1; if (인원 <= 7) return 1;` 는
> 두 분기가 같은 값이라 앞줄이 죽은 코드다.

## 5. ⭐⭐ 주도하면 찍힌다 — **사람이 구조적으로 불리하다**

`docs/soonsoon-feedback-2nd.md` §C-2 에서 잰 것이 **이 게임에 그대로 적용된다.**

- 고정 대화록에서 **주도적 제안을 한 사람이 표의 80%** 를 받는다.
- 그 대사를 다른 캐릭터에게 옮기면 **표도 그대로 따라간다**(성격 무관).
- 프롬프트로 막아 봤고 **안 됐다**(80.0% → 85.7% / 83.3%).

사람은 게임을 하려고 **당연히 대화를 이끈다.** 이끄는 순간 표적이 된다.
시민이면 억울하게 처형되고, 마피아면 오히려 조용히 있는 게 이득이라 재미가 죽는다.

**추가 측정 — `[사람]` 표시는 범인이 아니다.** 지목 프롬프트는 사람이 한 말에
`[사람]` 을 붙여 보여 준다. 이게 정체를 드러내는 단서인지 재 봤다:

| 조건 | 최다 득표 |
|---|---|
| 표시 없음 | 80.0% · 83.3% |
| **주도 발언자만 `[사람]` 표시** | **82.4%** |

오차 범위이고, 17개 답변 중 「사람/인간/플레이어」를 언급한 것이 **0건**이다.
→ **표시는 그대로 둬도 된다.** 문제는 표시가 아니라 **주도 그 자체**다.

**고치는 법(프롬프트로는 안 되므로 설계로):**
- ⓐ **AI 표의 무게를 낮춘다** — 예: 최다 득표가 과반이어야 처형(지금은 최다면 처형).
- ⓑ **대화록을 참여자마다 다르게 자른다** — 모두가 같은 「주도 장면」을 보지 않게.
- ⓒ **주도 발언을 분산시킨다** — 진행 멘트를 시스템(무기명)이 내보낸다.
  지금도 토론 첫 줄은 무기명이라 이 방향이 이미 half 쯤 되어 있다.
> ⓐ 가 제일 싸고 효과가 크다 **[추정]** — 재보지 않았다.

## 6. NPC 마피아가 **완전 무작위**로 죽인다

```js
const 대상 = 남은[Math.floor(Math.random() * 남은.length)];
```

전략이 없다. 마피아가 **자기를 의심한 사람**이나 **목격자**를 노리면
다음 날 토론이 즉시 달라진다("어제 저 사람이 나를 의심했는데 죽었다").
지금은 그 인과가 없어서 밤이 그냥 주사위다.

**고치는 법:** 어제 대화록에서 **범인을 지목했거나 근거를 댄 사람**에 가중치.
데이터는 이미 있다 — `기록[].찍은` 과 `근거`.

## 7. 작은 것들

- **근거 재요청이 10초 마감과 경쟁한다.** 첫 응답이 9초에 오면 재요청이 들어갈 자리가 없다.
  → 재요청분을 위해 마감을 조금 남기거나, 늦게 온 응답은 재요청을 건너뛴다고 명시.
- **`?demo=1` 시연 분기가 남아 있다.** 평시엔 안 켜지지만(URL 파라미터), 코드가 계속 붙어 있다.
  발표가 끝났으므로 지울지 남길지 정하는 게 낫다.

# 부록 A. 역할 구성 — 「6인에 마피아 2 + 의사 + 경찰 + 시민 2」가 맞나 (2026-08-24)

## 결론: **그 구성은 시민이 거의 못 이긴다.** 6인이면 마피아는 1명이어야 한다.

우리 승패 규칙(`roles.js`)은 표준이다 — **살아있는 마피아 ≥ 살아있는 시민이면 마피아 승**.
이 규칙으로 「시민이 **몇 번까지 헛다리를 짚어도** 되는가」를 세어 봤다(의사 세이브 없음 기준).

| 구성 | 마피아 | 타운 | **시민이 버틸 수 있는 오판** |
|---|---|---|---|
| **마2 · 의1 · 경1 · 시2 (6인)** | 2 | 4 | **0번** |
| 마1 · 의1 · 경1 · 시3 (6인) | 1 | 5 | 1번 |
| 마1 · 시4 (5인, 현재) | 1 | 4 | 1번 |
| 마2 · 의1 · 경1 · 시4 (8인) | 2 | 6 | 1번 |

**마피아 2명을 6인에 넣으면 오판이 0번 허용된다.** 첫 낮에 반드시 마피아를 맞혀야 하고,
한 번이라도 시민을 처형하면 그 자리에서 `마2 ≥ 시2` 가 되어 즉시 끝난다.

### 그런데 우리 AI 는 지목을 못 맞힌다

`soonsoon-feedback-2nd.md` §C 실측:

- AI 시민 지목 적중률 **11.8% ~ 23.5%** — **무작위(33.3%)보다 낮다**
- 표의 80% 가 **대화를 주도한 사람**에게 쏠린다(마피아가 누구인지와 무관)

**오판을 0번만 허용하는 구성 + 무작위보다 못 맞히는 투표자** = 사실상 마피아 자동 승리다.

> 참고로 **지금 코드가 이미 맞게 되어 있다.** `마피아수()` 는 7인 이하에 1명을 준다.
> 마피아 2명은 **8인부터**이고, 그건 표준 마피아 배분(대략 1/3 미만)과도 맞는다.

## 그러면 6인 권장 구성

> **마피아 1 · 의사 1 · 경찰 1 · 시민 3**

- 시민이 **한 번은 틀려도** 된다.
- 경찰이 매 밤 1명씩 조사 → 최대 3번의 정보.
- 의사가 밤 1회를 무효화 → 사실상 오판 여유가 한 번 더 생긴다.
- 능력자가 2명이라 **마피아도 누굴 먼저 죽일지 고민**하게 된다(지금은 무작위 살해라 고민이 없다).

## 마피아 2명을 정말 넣으려면 — 8인이 필요하고, **맵이 막는다**

`cast.js` 의 `최대출연 = 6` 은 임의로 정한 값이 아니다. **맵에 방이 6개**다.
8인을 하려면 둘 중 하나다.

| 방법 | 비용 |
|---|---|
| 맵에 방 2개 추가 | `tools/build-map.mjs` 로 재생성 + 연결성 검증. 스폰도 추가 |
| 방을 2인 1실로 | 밤 목격 판정(`목격거리`)이 **같은 방 사람을 항상 목격**하게 되어 규칙이 흔들린다 |

**방을 늘리는 쪽이 맞다** [추정 — 실제로 만들어 보지 않았다].

# 부록 B. 경찰(조사) 역할 — 구현은 쉬운데 **AI가 정보를 쓸지가 관건**

## 붙일 자리는 이미 있다

밤 조사 결과를 **그 캐릭터만 아는 사실**로 넣어야 하는데, 그 통로가 이미 있다 — `saw` 다.

```js
// round.js — 살해를 목격했을 때
a.saw.push(`${때} 자다가 깼는데, ${범인.name}가 … 다가가는 걸 봤다. 이건 확실하다.`);
```

```js
// engine.mjs — 프롬프트에 그대로 들어간다
...(saw.length ? [`- 그리고 **너만 본 것이 하나 있다:**`, ...saw.map(x => `  · ${x}`)] : [])
```

→ 경찰 조사 결과를 `saw` 에 밀어 넣으면 **프롬프트 배선을 새로 만들 필요가 없다.**

## ⚠ 그런데 AI가 그 정보를 쓸지는 **확인되지 않았다**

우리 실측은 AI 시민이 **근거가 아니라 「누가 주도했는가」로 찍는다**고 말한다.
경찰에게 "살살이는 마피아다"를 쥐여 줘도 **무시하고 주도자를 찍을 수 있다.**

**재기 전에 넣지 말 것.** `bias-probe` 로 바로 잴 수 있다:

> 고정 대화록은 그대로 두고, **투표자 한 명에게만** `saw: ["…살살이가 마피아다"]` 를 준다.
> 그 사람의 표가 살살이로 가면 → 정보가 먹힌다. 여전히 주도자를 찍으면 → 경찰이 무의미하다.

20회 호출(≈90 SSAM)이면 끝난다. **이 측정 없이 경찰을 넣는 건 도박이다.**
