## 1. 먼저 — 제가 손댄 부분을 알려 드립니다

### ① 신뢰도는 **제가 매기지 않았습니다** — 신서연님 표기 그대로입니다

처음엔 통합 표에 나란히 놓으려고 ★ 5단계로 환산했었는데, **그렇게 하니 신서연님이
스스로 낮춰 두신 등급을 제가 도로 올려 버리는 일**이 생겼습니다. **되돌렸습니다.**

지금은 **자체 4등급을 글자 그대로** 씁니다.

| 항목 | 표에 나오는 값 |
|---|---|
| Studio 규약 반대 · 자율배회 충돌 · `model` 404 | **해결됨** |
| 캐스트 저장소 손상 | **코드만 확인** |
| `blocksMovement` 미끼 | **출처만 확인** |
| Classify 미연결 · 건물 출입 | **미해결** |
| 참조 이미지 1024 | **표기 없음** *(아키텍처 절의 주석이라)* |

**제가 판단한 값이 하나도 없습니다.** 잘못 옮긴 게 있으면 말씀만 주세요.

### ② 회사 제품 문제만 골라 통합 표에 넣었습니다

신서연님 §06 에는 **회사 제품 문제**와 **직접 짠 코드 문제**가 섞여 있습니다.
통합 표는 회사에 드리는 것이라 **앞쪽만** 뽑았습니다 — 이 여덟 건입니다.

| # | 무엇 | 표에 나오는 등급 |
|---|---|---|
| 19 | 캐스트를 코드로 주입하면 캐릭터 저장소가 깨진다 | 코드만 확인 |
| 20 | Object Editor 의 Classify 가 통행 판정으로 안 이어진다 | 미해결 |
| 21 | 참조 이미지를 쓰면 1024 정사각형으로 찌그러진다 | 표기 없음 |
| 22 | **Studio 저장 규약과 엔진 런타임 규약이 정반대** | 해결됨 |
| 23 | `blocksMovement` 필드가 미끼 | 출처만 확인 |
| 24 | 자율 배회와 게임 길찾기가 동시에 돌아 위치가 어긋난다 | 해결됨 |
| 25 | 내장 대화가 `model` 에 품질 등급을 실어 404 | 해결됨 |
| 26 | 문틀 부분 가림을 못 해 건물 출입 미구현 | 미해결 |

전부 **신서연님이 붙이신 등급 그대로**입니다.

**#22 를 요청 A6 으로 올렸습니다.** 제품 안에서 두 규약이 반대라 사용자가 알아낼 방법이 없는 건,
저희가 모은 26건 중 **가장 무거운 축**이라고 봤습니다.

**직접 짠 코드 쪽**(증언판 오귀속 · 부정문 오지목 · 서버 다운 · 인젝션 가드 · 범인 자백 구멍 등)은
**「신서연」 탭에 사례로 남겼습니다** — 검증을 어떻게 했는지가 오히려 강점이라서요.

### ③ 겹침이 둘 나왔습니다

서로 상의하지 않았는데 **같은 것을 각자 만난 것**이 둘 있었습니다. 문서에서 **주황 띠**로 표시됩니다.

- **캐스트를 코드로 주입하면 깨진다** — 신서연님은 저장소가 통째로 깨졌고, 저는 배치가 전부 지워졌습니다.
  **둘 다 각자 「캐스트만은 코드로 하지 말라」를 자기 규칙으로 적어 뒀습니다.**
- **1024 정사각형이 강제된다** — 신서연님은 참조 이미지가 찌그러지는 것을,
  저는 품질을 올려도 1024 가 상한인 것을 봤습니다. **같은 벽의 두 얼굴입니다.**

그리고 **검증 등급을 각자 발명한 것**도 「독립적으로 같은 결론」으로 기록했습니다 —
신서연님 4등급과 제 ★ 5단계, **둘 다 등급을 내린 기록까지 남겼다는 점**이 같았습니다.

## 2. 부탁드릴 것 — 셋뿐입니다

주신 자료가 **여섯 항목 중 넷을 이미 채웁니다.** 특히 **「어디서 막혔나」는 네 사람 중 가장 충실합니다.**
그래서 **전체를 다시 쓰실 필요가 전혀 없고**, 아래 셋만 부탁드립니다.

| | 무엇 | 왜 |
|---|---|---|
| **①** | **스크린샷 2~4장** | **지금 문서에 이미지가 한 장도 없습니다.** 이게 제일 급합니다 |
| **②** | **실행 방법 한 줄** | 다른 탭엔 다 있습니다 (예: `bash serve.sh` → `localhost:5173`) |
| **③** | **회사에 하고 싶은 말 / 드릴 수 있는 것** | 지금 자료엔 이게 없습니다 |

### ① 스크린샷

대표님 앞에서 한 번 열어 보여 드리는 자료인데 **그림이 하나도 없어서 허전합니다.**

- 게임이 돌아가는 화면 (제일 중요)
- 심문 대화창 · 증언판 같은 특징적인 화면
- 있으면 — 막혔던 장면, 오류 화면

> ⚠ **앱 영역만 잘라 주세요.** 브라우저 창째로 찍으면 탭 제목·북마크·프로필 이름이
> 같이 올라갑니다. **공개 웹에 배포됩니다.**

### ③ 은 이 정도면 충분합니다

- **회사에 하고 싶은 말** — 「Studio 익히는 데 전체 시간의 90%」 를 이미 쓰셨는데,
  **그 얘기를 회사를 향해 한 문단으로** 풀어 주시면 그대로 씁니다.
  *“핵심 요구는 대화·기억이었는데 무대를 짓느라 거기 시간을 다 썼다”* 는 지적은
  회사가 들어야 할 말이라고 봅니다.
- **드릴 수 있는 것** — 재현 스크립트(`verify-dialogue-fixes.mjs` · `harness.mjs`),
  계측 로그, 재현 절차 중 넘기실 수 있는 게 있으면.
- **다음에 다르게 할 것** — 있으면 한두 줄.
