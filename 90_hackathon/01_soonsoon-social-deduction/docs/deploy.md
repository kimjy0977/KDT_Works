## 실플레이 배포 (Vercel)

### 준비돼 있는 것

| 파일 | 역할 |
|---|---|
| `proto/vercel.json` | 정적 서빙 + **빌드 때 vendor 미러링**(`vendor/` 는 회사 코드라 커밋 안 한다) |
| `proto/api/mafia-turn.mjs` | 브라우저와 SAM 사이의 **유일한 통로**. 초대 코드 검사 포함 |
| `proto/api/_store.mjs` | 초대 코드별 남은 크레딧. KV 가 있으면 차감, 없으면 확인만 |

### 절차

1. Vercel 프로젝트를 만들고 **Root Directory 를 `90_hackathon/01_soonsoon-social-deduction/proto` 로** 지정한다.
   (레포 루트로 잡으면 `vercel.json` 을 못 찾는다.)
2. 환경변수를 넣는다.

   | 이름 | 값 | 필수 |
   |---|---|---|
   | `SAM_API_KEY` | SAM 키 | **예** |
   | `INVITES` | `ABC12345:555,DEF67890:1110` (코드:한도SSAM) | **예** — 없으면 아무도 못 쓴다 |
   | `MODEL` | 기본 `claude-haiku` | 아니오 |
   | `KV_REST_API_URL` · `KV_REST_API_TOKEN` | 붙이면 **실제로 차감**한다 | 아니오 |

   ⛔ **키를 레포에 넣지 않는다.** 공개 저장소다.

3. 배포한다.

### 배포 직후 확인 — 이 순서로

1. `mafia.html` 이 열리는가
2. **초대 코드 없이** 판을 시작 → `403 초대 코드가 필요하다` 가 떠야 한다
   (안 뜨면 `INVITES` 가 안 들어간 것이다 — 그대로 두면 크레딧이 샌다)
3. 코드를 넣고 한 판 → 대사가 나오는가
4. `sam_account_usage` 로 실제 차감 확인 (한 판 ≈ **190 SSAM**)

## 🔥 함정

**배포에서만 죽는 자리가 있었다 (2026-08-26 수정).**
`engine.mjs` 가 키를 못 찾으면 `~/.claude.json` 을 읽었는데, 배포된 곳에는 그 파일이 없다.
`try` 가 없어서 **모듈을 불러오는 순간 예외로 죽었고**, 서버리스에서는 그게 그냥 500 으로만
보여 원인을 찾을 수가 없었다. 게다가 `process.exit(1)` 까지 있었다.
→ 지금은 조용히 빈 키를 주고, **호출할 때** 「SAM 키가 없습니다」로 알려 준다.
   내 컴퓨터에서는 예전처럼 바로 멈춘다(키 없이 돌다가 헤매지 않게).

**`vendor/` 는 커밋하지 않는다.** 회사 코드다. `vercel.json` 의 `buildCommand` 가
배포할 때 `mirror.mjs` 로 내려받는다 — 이 줄을 지우면 배포본이 흰 화면이 된다.

**크레딧은 배포하는 순간부터 샌다.** 링크를 아는 사람이 판을 돌릴 때마다 나간다.
초대 코드는 그걸 막으라고 있는 것이고, **`INVITES` 를 안 넣으면 코드 검사가 통과되지 않아
아무도 못 쓴다**(닫힌 쪽이 기본이다 — 안전한 방향으로 실패한다).
