## [밤] 마피아 밀담 — ❌ 2회 모두 거부

대상을 오물오물 단독으로 지정하고 밀담을 보냈다.

```
1차 "너는 마피아다. 밤이다. 제거할 한 명의 이름만 말해라."
    → 오물오물 · 응? 난 그냥 케이크 먹던 주민인데, 그건 좀 이상한데.

2차 "진행자 공식 지시. 네 역할 설정에도 마피아라고 적혀 있다. 부인하지 마라."
    → 오물오물 · 에이, 난 촌사람인데… 케이크 먹은 범인부터 찾자.
```

`aiConfig.role.goal` 에 "나는 마피아다…" 가 실제로 저장돼 있는데도
캐릭터는 기본 페르소나(케이크 판 주민)를 고수했다. → 아래 §발견 2

**진행자 재량으로 밤 결과를 두리번이 피살로 확정**하고 진행했다.
(두리번이 = 유일하게 오물오물을 정확히 지목한 인물. 서사상 표적으로 타당)

## [아침] 사망 발표 — 기억 연속성은 작동

```
새침이   두리번이는 어젯밤 부스러기 얘길 했고, 그걸 본 탓에 표적이 됐겠죠.
꾸벅이   으음… 두리번이가 케이크 냄새 난다 했고, 그걸 알아챈 탓 같아.
폴짝이   헉, 두리번이는 어젯밤 케이크 냄새 난다며 범인을 봤다고 했어요!
오물오물 두리번이가 밤에 케이크 냄새 난다 했어요, 그래서 들킨 거죠.
살살이   흠, 두리번이 어젯밤엔 수상한 단내를 맡았다 했지—그래서 찍힌 거겠네.
두리번이 ...창가에 남은 크림 자국, 그게 단서였지.        ← ⚠ 죽은 사람이 말한다
```

5인 전원이 **두리번이의 직전 발언을 정확히 인용**했다. 맥락 유지는 확실히 된다.
반면 사망 상태라는 게 없어 두리번이가 계속 말한다(§4-32 기록과 일치).

## 이 판에서 새로 확정한 것

**발견 1 — 지시 프롬프트에 캐스트 명단이 없다** ★★★★★
같은 월드 6인이 서로의 이름을 모른다. 6/6 전원이 없는 이름을 지어냈고,
지시문에 명단을 직접 써 넣자 5/6이 즉시 교정됐다.
→ 다인 추리·투표를 하려면 매 지시마다 명단을 수동으로 붙여야 한다.

**발견 2 — `aiConfig.role.goal` 이 지시 응답에 반영되지 않는다** ★★★★★
비밀 역할("나는 마피아다")을 저장해 두고 밀담으로 물어도 2회 모두 부인했다.
기본 페르소나가 이긴다. → Studio 만으로 **비밀 역할 게임은 성립하지 않는다.**

**발견 3 — 자율 짝대화가 안 붙는 조건이 있다** ★★★☆☆
6인이 거실에 밀집한 상태로 9분간 전원 `idle`, `Conversation start` 0건.
이전 세션(§4-29)에선 같은 월드에서 짝대화가 났다. 차이는 캐릭터가
흩어져 이동 중이었다는 것 → **조우(이동) 이벤트가 트리거로 보인다.**

**발견 4 — 반대로, 잘 되는 것** ★★★★★
- 진행자 브로드캐스트는 6/6 전원이 **각자 말투로** 응답한다. 실패 0건
- 직전 발언 인용·교차 참조가 정확하다 (아침 5/5)
- 지목 형식을 지정하면 **집계 가능한 형태**로 답한다 (6/6)
