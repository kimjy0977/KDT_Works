## 5. 🔥 함정 (전부 한 번씩 당한 것)

**5-1. 브라우저는 `claude-in-chrome` 을 쓴다.**
`Claude_Browser`(앱 내장)는 SPUM 로그인 세션이 없어서 아무것도 못 한다.
증상이 "권한 차단"처럼 보여도 원인은 이것.

**5-2. SPUM 세션은 30분쯤에 만료된다.**
`/api/me` 가 `{"user":null}` 이면 만료. 우측 상단 배지 → ACCOUNT → **「다시 로그인」** → 4초.
**비밀번호 안 물어본다.** 묻지 말고 바로 복구할 것.

**5-3. SPUM 쓰기는 반드시 `로컬 → 서버` 순서.**
`export()` 백업 → `localStorage.setItem` → `dispatchEvent('spum:studio-storage-write')`
→ `saveServerSnapshot('manual')` → **새로고침**. 서버에 직접 PUT 하면 다음 새로고침에 날아간다.

**5-4. 캐스트 "배치"만은 코드 금지.** `world.casts[]` 를 코드로 만들면 앱이 전부 지운다.
World Editor 에서 `+` → "배치" 버튼으로. (생성·수정·외형·맵레이어·mapId 교체는 코드로 잘 된다.)

**5-5. 타일셋 셀 크기는 이미지에서 계산.** `grid: "16x16"` 은 셀이 16px 이라는 뜻이 아니다.
**셀 = 이미지폭 ÷ 16.** 실제로 192px ÷ 16 = **12px**.

**5-6. 대용량 반환값은 컨텍스트를 태운다.** `read_network_requests` 로 이미지를 조회하면 base64 가
통째로 쏟아진다. `javascript_tool` 은 큰 값을 `[BLOCKED]` 처리하기도 한다 → **요약해서 반환할 것.**

**5-7. 한글 파일명은 유니코드 정규화(NFC/NFD)가 어긋난다.**
bash 로 보이는 이름이 PowerShell `-LiteralPath` 로 안 열릴 수 있다.
→ `Get-ChildItem` 으로 **실제 파일 객체를 얻어서** 다루고, 이름 문자열로 조립하지 말 것.

**5-8. 탭이 비활성이면 `requestAnimationFrame` 이 멈춘다.** FPS 0 이 떠도 코드 문제가 아니다.
검증은 `engine.pause()` → `engine.step(1/60)` 반복으로 **결정론적으로** 할 것.

## 6. 🔒 보안 — 이 레포는 PUBLIC 이다

`github.com/kimjy0977/KDT_Works` = **공개 레포.**

- **SAM 키를 어떤 파일에도 하드코딩 금지.** `.env` 또는 환경변수만.
- `claude mcp add --scope project` 금지 (레포 `.mcp.json` 에 키가 박힌다). `local`/`user` 사용.
- **회사 제공 자료(회사소개서·발표본·과제정의서 원본)는 커밋 금지.** `_local/` 에 두고 gitignore.
- 커밋 전: `grep -rn "sam-[0-9a-f]\{8\}" .`

**레포에 올리는 기준:** *공유해야 하거나 중요한 것만.* 이 레포는 회사에 보여줄 **쇼케이스**다.
회사 제공 문서·그 파생 요약·타사 조사·내부 미팅 자료는 `_local/` 에 두고 **커밋하지 않는다.**

> ⚠️ **미해결:** 과제정의서 원본이 **과거 커밋에 남아 있다.** 최신 커밋에서는 제거했지만
> 공개 히스토리에서 지우려면 **history 재작성(비가역)** 이 필요 → 주영님 승인 대기.

## 7. 규율

- **가역은 자율, 비가역만 확인.** 일상 commit·push는 알아서. **force push·history 재작성·삭제·개명·외부발송**은 주영님 확인.
- KDT_Works 는 **매니저 세션과 공유하는 단일 clone.** push 전 `git pull`, 동시 git 작업 금지.
- 우리 작업 경로는 `90_hackathon/soonsoon-social-deduction/` 안으로 한정.
- **확인 안 한 건 "확인 안 됨"이라고 말한다.** 7/7 이면 7/7, 2/5 면 2/5. 실패를 성공처럼 보고하지 않는다.
- **결과물에서 멀어지면 즉시 중단하고 보고한다.** (도구 파헤치기로 시간 태운 전례 있음)
- 산출물을 만들면 **즉시 실제로 적용해서 눈으로 확인한다.** (맵 만들어놓고 월드에 안 붙인 전례 있음)
