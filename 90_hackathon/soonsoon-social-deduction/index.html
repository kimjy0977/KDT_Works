A1 한 장르로 묶으면

"사회적 추리" — 숨은 배신자를 대화로 찾아내는 게임

쉽게 말해 형사·추리물과 같아요. 여럿 중 누군가는 몰래 배신자(스파이)예요. 겉으론 멀쩡한 척하죠. 나머지는 대화하고 캐물어서 그게 누군지 밝혀냅니다. 배신자는 거짓말로 숨고, 추리하는 쪽은 말의 앞뒤 모순을 잡아 정체를 드러냅니다.

익숙한 장면우리 게임에선
형사가 용의자 심문→ 자유 타이핑 심문
여러 진술 맞대보기→ 진술 모아 모순 찾기

A5 우리만의 "와" + 실제 모습

거짓말쟁이가 진짜 AI라는 것

추리물이나 마피아 게임에선 거짓말하는 게 사람. 우리는 그 자리에 AI. 정해진 대사 분기가 아니라 플레이어가 뭐라 하든 즉흥으로 거짓말하고, 앞말을 기억하고 반박해요. → 이게 곧 회사(SPUM+SAM)가 자랑하고 싶은 능력.

플레이어어젯밤 10시에 어디 있었어요?
용의자 B숙소에서 잤죠. 밤새 안 나갔는데요.
플레이어근데 A가 그 시간에 창고에서 당신을 봤다던데요?
용의자 B…아, 그, 잠깐 물 마시러 나갔던 것 같기도 하고.
⚑ "밤새 안 나갔다" ↔ "나갔던 것 같다" = 모순! NPC가 앞 대화를 기억해서 성립 — 이게 핵심 재미.

A6 한 판은 이렇게 흘러갑니다 (예시)

  1. 시작: 눈보라 산장, 금고의 기밀 파일이 사라졌다. 용의자 5명 중 1명이 스파이 — 누군지 아무도 모름(매 판 랜덤).
  2. 심문: 서재로 가 집사에게 "10시에 어디 있었나요?" → "주방에요." 주방으로 가 요리사에게 물으니 → "집사요? 못 봤는데요."
  3. 모순 포착: 두 진술이 어긋난다. 다시 집사를 추궁하자 말을 바꾼다(AI가 앞말 기억 + 거짓말).
  4. 지목: "스파이는 집사다" — 1회 지목.
  5. 결과: 진실표와 대조 → 맞으면 검거(승), 틀리면 스파이 도주(패). 전원 진실 공개.

▸ 이 흐름을 C탭(게임 설계)의 캐릭터·루프·공간으로 실제 구현.

B1 왜 이 방향인가 — 생각의 순서

이건 "게임"이 아니라 순순팩토리의 마케팅 쇼케이스다

❌ "뭘 만들지?"부터 시작하면 틀린다 — 그건 수단(게임)부터 고르는 것. 순서는 회사 목적 → 무엇을 마케팅 → 그래서 뭘 구현 이어야 함.

  1. 회사는 왜 이 과제를 냈나? 데모는 팔 제품이 아니라 순순팩토리를 알리는 쇼케이스다. (과제 §3~5)
  2. 그럼 무엇을 마케팅하나? SPUM(엔진) + SAM(AI) = "AI가 사는 게임을 쉽게 만드는 도구".
  3. 그 어필을 위해 뭘 구현? 두 도구의 강점이 가장 잘 "보이는" 데모 = AI가 성격·기억·거짓말로 사는 게임 → 그래서 소셜추리.
  4. "뭘 만들지"는 여기서 나온다. 우선순위도 어필 순서: AI 대화·기억·거짓말(SAM) · 공간·픽셀(SPUM) · config 한 줄(쉽게).

B1· 근거 — "쇼케이스다"는 우리 의견 아님 (제공파일 원문)

같은 브리핑을 들어도 해석이 갈리니, 과제정의서·발표 원문에서 직접 도출. 팀원 이견도 이걸로 정렬한다.

제공파일 원문 (과제·발표)그래서 = 쇼케이스
과제 §3: "쇼케이스·레퍼런스가 없어 외부 개발자 도입 진입장벽이 높다 → 데모가 필요"데모의 목적 = 도입 유도(마케팅)
과제 §4: "완벽 상용 X, '이런 게 되는구나' 데모면 충분" + "기술 블로그 1편"팔 제품이 아니라 설득 콘텐츠 요구
회사 = 도구 판매사(SPUM 에셋 1위 · SPUM Base 유료 멤버십 · SAM). 제공자료가 전부 자기 제품우리 데모 = 그 도구를 자랑할 재료
발표 시장 슬라이드: 무한경쟁 · 상위10%가 수익 85% → 생존=생산성 → AI로 빠르게데모 = 그 주장의 증거물

▸ 출처: 순순팩토리 과제정의서 §3(현재상황)·§4(기대하는 모습) + 8/14 발표 시장 슬라이드.

⚑ 오해 주의 — 우리가 '광고'를 만드는 게 아니다. 그들의 목적을 파악해 잘 만든 데모(재료)를 주면, 회사가 "이것도 되네·저것도 되네" 하며 블로그·유튜브·투자설명에 골라 씀. 우리 몫 = 가져다 쓸 만한 재료를 잘 만드는 것.

B1· SPUM · SAM 쉽게 이해 (팀 공유용)

SPUM = 몸·무대 🎮

픽셀 캐릭터·맵·움직임을 레고처럼 쉽게 조립하는 2D 웹 게임 엔진(원래 유니티 2D 캐릭터 1위 에셋). 게임에서 눈에 보이는 것 담당.

SAM = 두뇌 🧠

캐릭터에 AI 머리를 꽂아주는 중계기(LLM 프록시). 말 걸면 성격대로 답하고 기억. 챗지피티 같은 두뇌를 게임에 연결 = 생각·대화 담당.

= 회사가 파는 것: "이 둘로 AI가 사는 게임을 빠르게 만든다." 우리 데모 = 그 증거.

  • SPUM(엔진): 웹 → 설치 없이 브라우저 즉시 실행 · 픽셀 2D를 쉽고 빠르게
  • SAM(AI): 페르소나 · 자연어 대화 · 기억 · (보너스) NPC끼리 상호작용
  • 도입 유도: "이렇게 쉽게 만든다" 튜토리얼/블로그 = 데모의 진짜 목적
  • 증명할 한 방: "정해진 스크립트로는 불가능한 AI 대화가 진짜 된다"
  • 대상: 인디 개발자 · 블로그/유튜브 · 투자자

▸ 근거: 과제정의서 §3·§4·§5 원문 명시

B2 컨셉 확정

마피아/스파이 추리게임 "클루-lite"

  • 참가자(용의자) 4~8명 · 역할 전부 숨김 — 기본 6, 4~8 커스텀. 3명·역할 공개는 마피아 본질(숨은 배신자·긴장)이 죽음. NPC는 config(이름+페르소나+비밀) 라 추가가 쌈
  • 플레이어 = 무리 안 참가자 — 시민/스파이 역할을 받고 AI 사이에서 플레이. 관전(AI만) 모드도 지원 (C4 참가 모델 확정)
  • 긴급회의/대질 1라운드 보너스·목표 — 용의자들이 서로 의심·변호 = 마피아 본질 + AI 와
  • 레퍼런스: 클루 · 어몽어스 · AI Town

⚑ 팀 합의 포인트

"대화만으로 찾기"(순수 채팅) vs "공간+조사". → 대화 코어 유지(다른 분들 맞음) + 얇은 2D 공간 얹기. 순수 채팅이면 "SPUM 왜 썼냐"가 되고, 공간을 얹으면 챗봇이 아니라 'SPUM 게임'이 됨.

B3 ★ 핵심 — 회사 어필 ↔ 우리 게임

회사가 어필하려는 것우리 게임에서 이렇게
SPUM 웹 즉시 실행브라우저 localhost → 바로 플레이
SPUM 픽셀·공간·이동픽셀 공간을 걸어다니며 조사
SAM 페르소나용의자마다 다른 성격·거짓말
SAM 기억앞 진술 기억 → 모순 잡기
간단한 퀘스트/이벤트 (§4 명시)사건 해결 = 우리의 퀘스트(범인 지목)
SAM 상호작용 보너스용의자끼리 대질·변호
"스크립트로 불가능" 증명같은 상황, 다른 접근 → 다른 결과
도입 유도튜토리얼 1급 + "NPC 추가는 config(설정값) 한 줄"

B4 만들 범위 (3일)

이번에 (MVP)

  • 방 2~5개 분리 + 복도(NPC마다 roomId)
  • 참가자 4~8명(데모 3~5 우선) · 1명 스파이 · 역할 숨김
  • 플레이어 참가(시민 역할) · 걸어다니며 심문
  • 자유 타이핑 심문 + 기억(모순)
  • 투표·지목 → 결말
  • 튜토리얼 / README · MIT · serve.sh

되면 (보너스)

  • 플레이어가 스파이일 때(AI가 나를 투표)
  • 관전 맵 + 시점 카메라 전환
  • 긴급회의(NPC끼리 대질) · 단서 시스템
  • 표정/외형 변화(파츠교체 되면)

기능 수보다 대화의 질 우선. 데모는 3~5명이면 요건 충족.

역할 랜덤 배정→공간 심문(기억)→단서·대질 (보너스)→투표·지목→결과
성공 기준충족 방식상태
브라우저 즉시 실행SPUM 웹 · localhost충족

E1 일정 — 실작업 3일(화·수·목), 금 발표

  1. 화 · 스파이크 + "1명이 말한다": 오전 = 기술 검증 3개(SPUM 렌더 / SAM API 호출 / spum-world 예제). 오후 = 방 1~2개 + NPC 1명 대화 + 기억. // ②콘텐츠=세계관·페르소나·진실표, ③문서=README·MIT·serve.sh 뼈대
  2. 수 · "돌아가는 한 판": config로 4~8명(데모 3~5) 확장 + 방 분리 배치 + 플레이어 참가(시민) + 투표·지목→결말 = 플레이 가능 + 킬러 장면. // P3 아트 입힘
  3. 목 · 폴리시 + 발표: (되면) 관전 맵/카메라 · 플레이어=스파이 + 타이핑 연출·인젝션 방어 + 문서 마감 + 데모 리허설 + 정직한 한계

★최소선 = 수요일 끝에 "돌아가는 한 판". 밀리면 폴리시 버리고 루프·문서만.

E2 역할 분담 — 인원수 말고 "트랙"으로

코드 코어는 서로 꽉 물려 있어 실제 1~2명 분량. 4명이 각자 환경에서 코드를 나눠 만들면 병합 충돌·서로 대기로 오히려 느려짐. → 코드는 소수, 나머지는 코드 밖에서 병렬.

트랙인원하는 일
① 코드 코어1~2명 (개발 가능자)SPUM 렌더 · SAM 대화·기억 · 게임 루프 · 지목·승패 · 인젝션 방어. 한 레포·한 환경에서 짝코딩 or 1명 드라이버.
② 콘텐츠1명 (주영님)용의자 페르소나 · 진실표 · 세계관 · 픽셀 캐릭터/맵. 코드가 아니라 데이터·에셋으로 넘김 → 충돌 0.
③ 문서·QA·발표1명README/기술블로그 · 데모 대본 · 플레이테스트 · 발표 · 정직한 한계. 코드 안 건드림 → 충돌 0.

★ "코드 만지는 사람 최대 2명" 원칙. 누가 실제로 코딩 되는지 화요일 확인 — 개발 경험 없으면 억지로 코드에 넣지 말고 콘텐츠·테스트·발표로. 역할 = 머릿수 아니라 실제 스킬.

E3 먼저 확인할 것 — 리스크

① SPUM(JS) 실행 중 파츠 교체·애니 전환 되나?

C2 랜덤 역할 시스템 (성격 = 고정 · 역할 = 랜덤)

인물은 성격만 정의(역할 없음). 여러 배우가 있는 극단에서 이번 공연에 몇 명만 캐스팅되듯, 풀에서 뽑고 스파이는 그때 랜덤으로 정해짐. 스토리를 짜는 게 아니라 데이터(진실표)를 판마다 새로 생성.

▸ 아래 코드는 개발 트랙용 — 콘텐츠·발표 팀원은 "인물은 성격만 정하고, 스파이는 매 판 랜덤" 개념만 알면 됩니다.

// 캐릭터 = 성격만 고정. "역할" 칸 없음.
캐릭터 = { 이름, 국적, 성격, 개인비밀, 공략법 }

게임시작():
  cast = 풀(20명+)에서 N명 뽑기        // N = 4~8, 사람 자리 빼고
  spy  = cast 중 랜덤 1명              // ← 매 판 달라짐
  진실표 = { 범인: spy, 사건:"파일 도난",
            각자 알리바이 } → 파일 저장   // 스토리 아님, 데이터

NPC_프롬프트(c) = c.성격 + c.개인비밀 + 대화기록
  + (c == spy
       ? "네가 훔쳤다. 숨기고 그 성격대로 거짓말."
       : "넌 결백. 근데 개인비밀은 들키기 싫다.")

C3 게임 루프 (한 판) — 2순위 핵심

용의자 뽑기→스파이 랜덤 배정→자유 심문(기억)→대질→스파이 지목→진실표 대조·승패
  1. ① 세팅: 눈보라 산장 고립, 금고 파일 도난. 풀에서 용의자 N명(4~8) 뽑기.
  2. ② 역할 랜덤 배정: 뽑힌 N명 중 1명 = 스파이. 나머지 결백(단 각자 개인비밀 有). → 진실표 파일 저장.
  3. ③ 심문: 플레이어가 자유 타이핑으로 질문. NPC는 성격+기억으로 답(스파이는 거짓, 결백도 개인비밀은 방어). 진술·모순을 메모.
  4. ④ 대질 보너스: "A가 이랬다" 전달 → B 반응. 용의자끼리 티격태격.
  5. ⑤ 지목: 플레이어가 스파이 1명 지목.
  6. ⑥ 판정·엔딩: 진실표 대조 → 맞으면 승(검거) · 틀리면 패(스파이 도주). 결과 카드로 전원 진실 공개.

저장되는 상태(= 과제 "외부 보존" 겸함): 진실표(누가 범인·알리바이) · NPC별 대화기록 · 플레이어 노트 → 파일. 껐다 켜도 재개 가능.

전원 개인 비밀이 있어 결백해도 뭔가 숨김 → 범인이 안 튐. 스파이는 매 판 랜덤(아래는 성격만 고정, 역할 없음).

제임스 위트모어 🇬🇧 · 주최자 · 침착·논리형

  • 비밀: 회사 파산 직전(빚)
  • 알리바이: "10시 서재에서 서류 검토"
  • 거짓말·공략: 논리·숫자로 포장 → 재정·시간 모순 파면 흔들림

메이린 🇸🇬 · 비서 · 감정·불안형

  • 비밀: 경쟁사와 몰래 접촉(이직 타진)
  • 알리바이: "주최자 곁에 계속 있었어요"
  • 거짓말·공략: 과잉 협조·감정적 부인 → 안심시키면 말실수

디에고 알바레스 🇪🇸 · 파트너 · 능청·궤변형

  • 비밀: 주최자와 돈 다툼(투자 회수 요구)
  • 알리바이: "바에서 한잔했지"
  • 거짓말·공략: 농담·화제 전환 → 같은 질문 반복하면 말 바뀜

소피 로랑 🇫🇷 · 예술가 · 도도·회피형

  • 비밀: 위작을 진품으로 판매
  • 알리바이: "갤러리 룸에서 작업 중"
  • 거짓말·공략: 우아하게 무시·회피 → 자존심 세워주면 유도됨

콰메 오세이 🇬🇭 · 경비 · 무뚝뚝·과묵형

  • 비밀: 사건 시각 자리 비움(잠깐 이탈)
  • 알리바이: "정문에서 근무 중"
  • 거짓말·공략: 단답·말 아낌 → 신뢰 쌓고 구체 동선 추궁

▸ 스파이가 되면: 알리바이가 실제와 어긋나게 바뀌고(범행 장소=금고방), 개인비밀 위에 "파일 훔친 것"을 추가로 숨김.

G2 진실표 예시 — "이번 판" (스파이 = 디에고)

스파이는 매 판 랜덤. 이건 한 예시일 뿐 — 게임이 이런 표를 자동 생성해 파일로 저장하고, 지목 시 대조함.

인물진짜 있던 곳정체
제임스서재 (진술 일치)시민
메이린주최자 곁 (일치)시민
디에고금고방 ← "바에 있었다"는 거짓★스파이
소피갤러리 룸 (일치)시민
콰메정문 잠깐 이탈 (딴 비밀)시민

★ 디에고만 알리바이가 실제와 어긋남 → 그게 결정타. 콰메도 자리를 비웠지만 파일과 무관(레드헤링) — 그래서 헷갈리게 만듦.
