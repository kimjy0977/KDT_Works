# 누가 내 케이크 먹었어?

**함께 사는 여섯 명 중 한 명이 되어, 밤 사이 냉장고의 케이크를 훔쳐 먹은 범인을 찾아내는 AI 소셜 추리 게임.**

모두의연구소 아이펠 · AI Agent 과정 기업연계 프로젝트 — **주식회사 순순팩토리**
팀 《순순히 따라와라》 · SPUM Engine + SAM LLM

---

## 실행

```bash
bash serve.sh
```

→ http://localhost:5173/game.html

이동 **WASD**/방향키 · 말 걸기 **E** · 전체 토론 **T** · 냉장고 **F** ·
전체맵 **M** · 닫기 **ESC** · 확대축소 **-** **=**

시작하면 **무대**(셰어하우스 / 우주선 격리구역)와 **모드**(직접 참여 / AI 관전)를 고릅니다.

Node.js 외 설치 없음. 대화 기능을 쓰려면 SAM 키가 필요합니다:

```bash
cp .env.example .env
```

`.env` 에 `SAM_API_KEY` 를 넣으세요. **`.env` 는 커밋되지 않습니다**(`.gitignore`).
키 없이도 맵·이동·캐릭터는 정상 동작합니다.

## 무엇이 특별한가 — 근거 있는 거짓말

LLM 에게 "범인 역할을 해줘"라고 시키면 매번 다른 얘기를 지어냅니다. 추리가 성립하지 않습니다.

그래서 **시스템이 정답(ground truth)을 먼저 고정하고, 각 캐릭터에게는 자기 기억만 줍니다.**

- **물리 단서**: 범인 소매의 딸기 시럽 자국 — 확정적
- **목격**: 동선이 겹칠 때만 발생 — 보장되지 않음
- **레드헤링**: 무고한 사람도 밤에 부엌에 갈 수 있음 (케이크는 그대로였음)
- **범인 배정**: **매 판 랜덤** — 플레이어도 범인이 될 수 있습니다.
  서버의 밤 시뮬레이터(`proto/night.mjs`)가 판마다 동선·목격·단서를 새로 생성합니다

대화 규칙을 프롬프트로 강제합니다:

1. 자기 기억에 있는 것만 말한다. 없으면 "기억 안 나" — **지어내기 금지**
2. 범인은 **자기 동선만** 거짓말한다. 타인 정보는 사실대로
3. 서로 다른 결정적 증거로 **3회 이상 몰리면 자백**

**자동 검증 `proto/run.mjs` — 7개 항목.** 실측: 2회 실행에서 **7/7 · 6/7**.
흔들린 한 항목은 레드헤링(무고한 사람의 부엌行)이며, 코드 문제가 아니라 **LLM 응답 변동**입니다.
나머지 6개는 두 번 다 통과했습니다. 실제로 재현된 자백:

```
[압박3] 꾸벅이도 자정쯤 냉장고 문 닫히는 소리를 들었대. 이래도 방에 있었다고 할 거야?
  살살이: *얼굴이 굳어지고 손이 떨린다*   내가... 내가 먹었어.
```

## 게임 루프

```
시작  무대 고르기 → 모드(참여/관전) → 캐릭터 고르기 → 내 역할 확인
  ↓
저녁  거실에 모여 전체 토론 (T) · 최소 한 명과는 이야기해야 넘어간다
  ↓
밤    각자 방으로 · 화면이 어두워지고 시야가 좁아진다
      범인이라면 부엌에서 F 로 케이크를 먹는다 — 근처에 사람이 있으면 목격당한다
  ↓
아침  케이크가 사라진 것을 발견
  ↓
토론  전체 채팅으로 알리바이 심문 · 개별 심문은 가까이 가서 E
  ↓
지목  한 명씩 이름을 대고 다수결 → 승패 판정
```

각 단계에는 제한 시간이 있습니다(저녁 130초 · 밤 80초 · 토론 200초).

**대사는 한 글자씩 나옵니다.** 응답은 통째로 도착하지만 사람이 치는 속도로 되풀어 주고,
캐릭터마다 타자 속도가 다릅니다(폴짝이는 빠르고 꾸벅이는 느립니다).
답답하면 채팅창 헤더의 **1x / 3x / 즉시** 버튼, 또는 클릭·**Space** 로 건너뜁니다.

## 📖 구현 튜토리얼

**[docs/tutorial.md](docs/tutorial.md)** — SPUM Engine 위에 AI NPC 게임을 붙이는 전 과정.
엔진에 문서가 없어 소스를 읽어가며 만들었고, **밟은 함정 11가지를 전부 적었습니다.**

- 타일맵·카메라·충돌을 붙이는 법과 이름 때문에 오해하기 쉬운 API
- `PathfindingManager` + `NavAgent` 로 NPC 를 스스로 걷게 하기
- SAM 연결 · 키 보안 · **"기억에 없는 것은 지어내지 않는다"를 만드는 프롬프트 설계**
- **`spum-world` 대화 모듈을 왜 쓰지 않았는가** (순순팩토리에 드리는 피드백 포함)
- 타이밍에 의존하지 않는 **결정론적 검증** 방법

├─ pitch/            발표 자료 · SPUM 사용 가이드
└─ proto/
   ├─ game.html      ★ 게임 화면 (껍데기 · 로직은 src/)
   ├─ src/
   │   ├─ main.js      부팅
   │   ├─ setup.js     시작 화면 · 무대/모드/캐릭터 고르기
   │   ├─ world.js     엔진·타일맵·캐릭터·카메라·길찾기
   │   ├─ worlds.js    무대 목록 + 무대별 어휘 치환
   │   ├─ ai.js        NPC 배회 (NavAgent)
   │   ├─ talk.js      근접 대화 · 맥락 유지
   │   ├─ npctalk.js   NPC 끼리의 대화 · 엿듣기
   │   ├─ groupchat.js 전체 토론 · 지목 라운드
   │   ├─ typing.js    대사를 사람 타자 속도로 출력
   │   ├─ phase.js     게임 루프 · 밤 시야 · 목격 기록
   │   ├─ minimap.js   미니맵 (시야 안의 사람만 보인다)
   │   ├─ sprite.js    캐릭터 시트 · 걷기 모션
   │   ├─ snap.js      좌표 보정
   │   └─ cast.js      거주자 표시정보 · 배회 목적지
   ├─ server.mjs     로컬 서버 + SAM 프록시 (키는 서버에만)
   ├─ engine.mjs     캐릭터 데이터 + 프롬프트 빌더
   ├─ night.mjs      밤 시뮬레이터 — 매 판 범인·동선·목격을 새로 만든다

   ├─ tools/         맵 생성기 · PNG 툴킷 · 배경 제거 · 타일 뷰어
   └─ assets/        맵 · 타일셋 · 캐릭터

## 기술 구성

| 층 | 사용 |
|---|---|
| 런타임 | **SPUM Engine** — `Engine`·`TileMap`·`Camera`·`InputManager`·`SpriteRenderer` |
| 에셋 저작 | **SPUM Studio** — Object(**AI 평면도**) · Map · Cast(**6명** · idle+걷기 시트) · World |
| 무대 | **2개** — 셰어하우스(32×32) · 우주선 격리구역(64×64). 무대가 바뀌면 등장인물의 어휘도 바뀐다 |
| 대화 AI | **SAM** `/v1/generate` (서버 프록시 경유, 키 미노출) |

맵은 손으로 찍지 않고 `proto/tools/build-map.mjs` 가 생성합니다.
현재는 **AI가 생성한 평면도 한 장**을 맵에 1:1로 깝니다(셀 32px = 게임 타일 크기).
초기에는 타일 시트를 조각내 재조립했으나(스탬프), 벽 구조와 밀도가 살지 않아 바꿨습니다.
생성 직후 **모든 스폰의 상호 도달 가능성을 검사**해 실패하면 빌드를 중단합니다.
닫힌 방이 생기면 `tools/carve-doors.mjs` 가 가장 얇은 벽을 뚫고 그 자리에 이웃 바닥 타일을 깝니다.
