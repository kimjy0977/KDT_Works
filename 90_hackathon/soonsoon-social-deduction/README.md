# 누가 내 케이크 먹었어?

**셰어하우스 거주자 5명 중 한 명이 되어, 밤 사이 냉장고의 케이크를 훔쳐 먹은 범인을 찾아내는 AI 소셜 추리 게임.**

모두의연구소 아이펠 · AI Agent 과정 기업연계 프로젝트 — **주식회사 순순팩토리**
팀 《순순히 따라와라》 · SPUM Engine + SAM LLM

---

## 실행

```bash
bash serve.sh
```

→ http://localhost:5173/game.html

이동 **WASD**/방향키 · 말 걸기 **E** · 냉장고 **F** · 닫기 **ESC** · 확대축소 **-** **=**

Node.js 외 설치 없음. 대화 기능을 쓰려면 SAM 키가 필요합니다:

```bash
cp .env.example .env
```

`.env` 에 `SAM_API_KEY` 를 넣으세요. **`.env` 는 커밋되지 않습니다**(`.gitignore`).
키 없이도 맵·이동·캐릭터는 정상 동작합니다.

---

## 무엇이 특별한가 — 근거 있는 거짓말

LLM 에게 "범인 역할을 해줘"라고 시키면 매번 다른 얘기를 지어냅니다. 추리가 성립하지 않습니다.

그래서 **시스템이 정답(ground truth)을 먼저 고정하고, 각 캐릭터에게는 자기 기억만 줍니다.**

- **물리 단서**: 범인 소매의 딸기 시럽 자국 — 확정적
- **목격**: 동선이 겹칠 때만 발생 — 보장되지 않음
- **레드헤링**: 무고한 사람도 밤에 부엌에 갈 수 있음 (케이크는 그대로였음)
- **범인 배정**: 현재는 **고정 시나리오 한 판**입니다. 매 판 랜덤 배정은 기획에는 있으나 **아직 미구현**

대화 규칙을 프롬프트로 강제합니다:

1. 자기 기억에 있는 것만 말한다. 없으면 "기억 안 나" — **지어내기 금지**
2. 범인은 **자기 동선만** 거짓말한다. 타인 정보는 사실대로
3. 서로 다른 결정적 증거로 **3회 이상 몰리면 자백**

**검증 결과 7/7 통과** (`proto/run.mjs`). 실제로 재현된 자백:

```
[압박3] 꾸벅이도 자정쯤 냉장고 문 닫히는 소리를 들었대. 이래도 방에 있었다고 할 거야?
  살살이: *얼굴이 굳어지고 손이 떨린다*   내가... 내가 먹었어.
```

## 📖 구현 튜토리얼

**[docs/tutorial.md](docs/tutorial.md)** — SPUM Engine 위에 AI NPC 게임을 붙이는 전 과정.
엔진에 문서가 없어 소스를 읽어가며 만들었고, **밟은 함정 11가지를 전부 적었습니다.**

- 타일맵·카메라·충돌을 붙이는 법과 이름 때문에 오해하기 쉬운 API
- `PathfindingManager` + `NavAgent` 로 NPC 를 스스로 걷게 하기
- SAM 연결 · 키 보안 · **"기억에 없는 것은 지어내지 않는다"를 만드는 프롬프트 설계**
- **`spum-world` 대화 모듈을 왜 쓰지 않았는가** (순순팩토리에 드리는 피드백 포함)
- 타이밍에 의존하지 않는 **결정론적 검증** 방법

## 구조

```
├─ serve.sh          실행 스크립트
├─ index.html        기획서 (한 장 스크롤)
├─ docs/             작업 문서 (기획·규칙·엔진 감사·이력)
├─ pitch/            발표 자료 · SPUM 사용 가이드
└─ proto/
   ├─ game.html      ★ 게임 화면 (껍데기 · 로직은 src/)
   ├─ src/
   │   ├─ main.js      부팅
   │   ├─ world.js     엔진·타일맵·캐릭터·카메라·길찾기
   │   ├─ ai.js        NPC 배회 (NavAgent)
   │   ├─ talk.js      근접 대화 · 맥락 유지
   │   ├─ phase.js     게임 루프 · 밤 시야
   │   └─ cast.js      거주자 표시정보
   ├─ server.mjs     로컬 서버 + SAM 프록시 (키는 서버에만)
   ├─ engine.mjs     캐릭터 데이터 + 프롬프트 빌더
   ├─ run.mjs        근거 엔진 자동 검증 (7/7)
   ├─ tools/         맵 생성기 · PNG 툴킷 · 배경 제거 · 타일 뷰어
   └─ assets/        맵 · 타일셋 · 캐릭터
```

## 기술 구성

| 층 | 사용 |
|---|---|
| 런타임 | **SPUM Engine** — `Engine`·`TileMap`·`Camera`·`InputManager`·`SpriteRenderer` |
| 에셋 저작 | **SPUM Studio** — Object(**AI 평면도** 32×32 · 셀 32px) · Map · Cast(5명) · World |
| 대화 AI | **SAM** `/v1/generate` (서버 프록시 경유, 키 미노출) |

맵은 손으로 찍지 않고 `proto/tools/build-map.mjs` 가 생성합니다.
현재는 **AI가 생성한 평면도 한 장**을 맵에 1:1로 깝니다(셀 32px = 게임 타일 크기).
초기에는 타일 시트를 조각내 재조립했으나(스탬프), 벽 구조와 밀도가 살지 않아 바꿨습니다.
생성 직후 **스폰 7곳의 상호 도달 가능성을 검사**해 실패하면 빌드를 중단합니다.
