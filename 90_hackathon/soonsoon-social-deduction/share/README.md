# 팀 공유 — SPUM / SAM 작업 자료

> 팀 《순순히 따라와라》가 SPUM Studio + SAM 으로 실제 작업하며 얻은 것입니다.
> **SPUM Studio 는 공식 문서·튜토리얼이 사실상 없어서**, 지금은 이게 팀이 가진 가장 정확한 자료입니다.
> 모든 항목에 **신뢰도 ★** 를 붙였습니다 — 아래 기준입니다.

| 표기 | 뜻 |
|---|---|
| ★★★★★ | 우리가 **직접 해보고** 확인함 |
| ★★★★☆ | **소스/문서 근거** — 코드는 읽었으나 실행까지는 안 해봄 |
| ★★★☆☆ | 추정 |
| ★★☆☆☆ | 불확실 |
| ★☆☆☆☆ | 미확인 |

★★★★★ 가 아닌 항목은 본인 환경에서 한 번 확인하고 쓰세요.

## ⛔ 급하면 이것만 — 모르면 무조건 당하는 3가지

1. **서버에 직접 쓰면 작업이 날아갑니다.** SPUM 은 브라우저 `localStorage` 가 원본입니다.
   반드시 `localStorage` 수정 → `saveServerSnapshot()` → 새로고침 순서. ★★★★★
2. **세션이 30분쯤에 만료됩니다.** `/api/me` 가 `{"user":null}` 이면 만료.
   ACCOUNT → 「다시 로그인」 4초, **비밀번호 안 물어봅니다.** 권한 문제로 오해하기 쉽습니다. ★★★★★
3. **World 내장 AI 는 게임 규칙에 못 씁니다.** `systemPrompt` 를 무시하고, 기억을 근거로 안 쓰고, 지어냅니다.
   대화 로직은 **SAM 직접 호출**로 만드세요. ★★★★☆

## 읽는 순서

### 1️⃣ 처음 SPUM 을 여신다면 — 화면 가이드

**[`../pitch/spum-guide.html`](../pitch/spum-guide.html)** *(브라우저로 여세요)*

각 에디터 화면을 캡처해 ①②③ 번호를 얹고, 아래 설명을 같은 번호로 달았습니다.
**Home → Cast(캐릭터) → Object(타일) → Map(공간) → World(조립)** 순서 — 이게 곧 제작 순서입니다.

> 여기서 **Object 와 Map 의 차이**를 먼저 잡고 가세요. Object = 타일 "그림"을 만드는 곳,
> Map = 그 타일로 "배치"하는 곳입니다. 헷갈려서 시간 버리는 분이 많습니다.

### 2️⃣ Claude 를 쓰신다면 — 하네스 복사

**[`CLAUDE.md`](CLAUDE.md)** 를 본인 **프로젝트 폴더 루트에 복사**하세요.
그 폴더에서 세션을 열면 규칙이 자동 적용됩니다. 맨 위 **§0 만** 각자 채우면 됩니다.

담긴 것: 보안(키 취급) · **SPUM 함정 9종** · **브라우저 자동화 함정 6종** · 환경 함정 5종 ·
엔진에 있는 것/없는 것 · git 주의.

> 규칙 없이 시작하면 우리가 겪은 걸 그대로 겪습니다 —
> 서버에 직접 써서 작업이 날아가고, 세션 만료를 권한 문제로 오진하고,
> 타일 셀 크기를 착각해 헤매고, 키 접두사를 문서에 적어 git 히스토리를 재작성하게 됩니다.
