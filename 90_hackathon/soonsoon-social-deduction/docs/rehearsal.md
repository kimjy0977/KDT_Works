> **결론 먼저:** 시연은 **케이크 판(`game.html`)이 주력**입니다.
> 마피아 판(`mafia.html`)은 오늘 만든 확장이라 **보너스로 짧게만** 보여주세요.
> 마피아 판이 리허설 중 이상하게 굴어도 발표는 케이크 판만으로 성립합니다.

## 2. 말할 것 — 문장 그대로

### ① 무슨 게임인가 (0:30)

> "「누가 내 케이크 먹었어?」입니다. **마피아를 AI로 돌린 게임**이에요.
>
> 규칙 세 줄. 밤에 여섯 중 하나가 냉장고 케이크를 먹습니다. **범인은 매 판 랜덤이고 플레이어도 뽑힙니다.**
> 아침에 모여 심문합니다. NPC 는 **자기가 그날 밤 실제로 한 일만** 기억합니다.
> 투표로 범인을 지목하면 이깁니다.
>
> 핵심은 이겁니다. **AI가 즉흥으로 지어내는 게 아닙니다.**
> 시스템이 밤을 먼저 시뮬레이션해서 정답을 고정하고, 각자에게는 **자기 기억만** 줍니다.
> 그래서 대조하면 **모순이 나옵니다.** 그게 단서예요."

> 🔑 **랜덤 · 자기 기억만 · 모순** — 이 세 단어는 반드시 말할 것.

### ② SPUM 도달점과 한계 (1:00)

> "먼저 **SPUM Studio 만으로** 어디까지 되는지 확인했습니다.
> 마피아 판을 세팅해 **한 판 완주했습니다. 9분, 165 SSAM. 시민이 이겼고 실제 마피아를 맞혔습니다.**
>
> 잘 된 것 — 진행자가 지시하면 **6명 전원 무결 응답**, 앞 대화 인용 5건, 형식 준수 6/6.
> **진행자가 있는 대화극에는 Studio 만으로 충분합니다.**
>
> 막힌 것 두 가지.
> 하나, **지시 프롬프트에 캐스트 명단이 안 들어갑니다** — 6명 전원이 없는 이름을 지어냈어요.
> 둘, **비밀 역할이 응답에 반영되지 않습니다** — 마피아로 지정한 캐릭터가 두 번 다 그냥 부인했습니다.
>
> 이 둘이 정확히 **마피아류를 막습니다.** 그래서 이 부분을 직접 만들었습니다."

### ③ 케이크 판 시연 (1:50) — **관전 모드로**

| 순서 | 조작 | 말 |
|---|---|---|
| 1 | 타이틀 → **AI 관전** | "SPUM 으로 만든 캐릭터·맵을 그대로 씁니다. 에셋은 전부 SPUM 제작본이에요." |
| 2 | 무대 → 셰어하우스 | "무대는 둘. 셰어하우스와 우주선." |
| 3 | 출연진 화면 | "**10명 중 골라서** 한 판을 짭니다." |
| 4 | 저녁 단계 | "저녁에 나눈 말이 **내일 아침 알리바이**가 됩니다." |
| 5 | 밤 (어두워짐) | "밤엔 시야가 좁아지고, 이때 범인이 부엌으로 갑니다." |
| 6 | 아침 → 토론 | "케이크가 사라졌습니다. 심문 시작." |
| 7 | **`N` 단서 수첩** | "들은 말에서 **누가·언제·어디**를 자동으로 뽑아 표로 만듭니다. **모순은 빨갛게** 뜹니다." |
| 8 | 발언 행동 패널 | "자유 입력 말고 **행동으로도** 말합니다 — 캐묻기·모순 짚기·감싸기. 그노시아 방식." |
| 9 | 투표 → **결과판** | "**어몽어스처럼 누가 누구를 찍었는지 얼굴로** 보여 줍니다." |

**응답이 늦을 때 메울 말:**
> "지금 응답을 기다리는데, 이 대기를 그냥 두면 게임이 죽습니다.
> 그래서 **다음 사람 응답을 미리 받아 두고**, 앞사람 대사가 **사람 타자 속도로** 찍히는 동안 감춥니다.
> 캐릭터마다 타자 속도도 달라요 — 폴짝이는 빠르고 꾸벅이는 느립니다."

### ④ 마피아 판 30초 (선택)

> "그리고 오늘, **진짜 마피아 규칙**을 로컬에 따로 구현했습니다.
> 밤에 각자 방으로 가서 자고, **마인크래프트처럼 모두 잠들면** 마피아만 움직입니다.
> 죽으면 **화면이 흑백이 되고 유령이 됩니다** — 유령끼리만 서로 보입니다.
> 아까 말한 **SPUM 에서 안 되던 비밀 역할**을, 게임 상태를 코드로 내려서 해결한 겁니다."

> 화면은 **밤 장면 + 참여자 바**만 보여주고 넘기세요. 한 판을 다 돌리면 시간이 없습니다.

### ⑤ 결론 (0:40)

> "정리하면.
> **SPUM Studio 는 진행자가 있는 대화극까지 갑니다.** 한 판 완주해서 확인했습니다.
> **거기서 막히는 게 캐스트 인지와 비밀 역할**이고, 그게 정확히 마피아류를 막습니다.
> 그래서 **SPUM 을 에셋 저작소로 쓰고, 로직과 대화는 SAM 을 직접 불러** 만들었습니다.
> 매 판 범인이 바뀌고, 단서가 새로 생성되고, 모순이 잡히는 추리 게임입니다. 감사합니다."

## 3. 리허설 직전 체크 (3분)

- [ ] `bash serve.sh` 떠 있나
- [ ] `game.html?demo=1` 로 **관전 한 판** 돌려보기 (실제 소요 시간 측정)
- [ ] SAM 키 살아 있나 — `node run.mjs` 한 번
- [ ] SSAM 잔액 — 시연 한 판에 약 100~170
- [ ] **SPUM Studio 는 Pause 상태인가** (아니면 발표 중에도 과금)
- [ ] 브라우저 100% · **탭을 앞에 둘 것** (배경 탭이면 타이핑 연출이 멈춤)
- [ ] `docs/logs/mafia-round-2026-08-20.md` 미리 열어 두기

## 4. 하지 말 것

- ⛔ **발표 중 SPUM Studio 라이브 접속** — 세션 30분 만료 · `Generating` 멈춤 전례

- ⛔ **마피아 판 한 판 완주 시도** — 밤~투표까지 2분 넘게 걸립니다. 화면만 보여주세요
- ⛔ 기능 전부 보여주기 — 설정·줌·미니맵은 **질문 받으면** 꺼내세요
