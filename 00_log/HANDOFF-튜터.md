## 4. 규칙 (반영 완료, 어기지 말 것)

- **★`git add -A` 금지 + 폴더 add 도 금지 — «파일»을 찍는다** (§C, 2026-08-31 개정)
  `git add 00_log/index.html 00_log/회고.html`. 폴더 add 는 «add 하는 그 순간의 폴더 전체»라,
  다른 세션·프로세스가 그 사이 쓴 파일이 딸려 온다. **실사고 `54ff1e5`** — UI 커밋에 벡터스토어 26MB.
  커밋 직전 `git status --short`, push 전 `git pull`. (구 규칙 "동시 git 작업 금지"는 폐지)
- **★§B-2 프로젝트 경계 = 쓰기 금지선** (2026-08-31 신설) — 타 프로젝트 폴더는 **읽기만**.
  생성·수정·삭제 금지 → 그 세션에 **요청**. **«읽으라» ≠ «거기 쓰라».**
  산출물 소속은 파일 위치가 아니라 **«어느 프로젝트의 일인가»**. 실사고: GMDV 문서에 v0.2 를 써 넣었다.
- **★§F-8-A ⑧ 잘린 목록 금지** — `tail`·`head` 로 본 걸 «전부»라고 적지 않는다. 세려면 `wc -l` 같은 집계 명령.
- **★§F-11 세션 작업기록** — `02_tutor/작업기록/YYYY-MMDD~MMDD_계정.md` 에 **작업 단위마다**. ⛔몰아쓰기 금지.
- **★§H-4 규칙 고치면 예시도** — 규칙 문장만 고치면 **예시가 반대를 가르친다**. 정본→하네스→예시를 같은 날.
  ※ 위 다섯은 **`02_tutor/CLAUDE.md` §6-9** 에 포인터로 들어가 있다. **하네스에 없으면 «없는 규칙»이다.**
- **브리지는 append-only** — 새 글은 **맨 아래**. 최신이 아래다.
- **브리지 ID** = `KBTM-T-YYYYMMDD-N` (세션코드 **T** 필수) + `발신: 튜터` 줄.
- **노드를 새로 넣을 때 다섯 곳**을 모두 고친다 → 가이드 §1-4b. 빠뜨리면 조용히 깨진다.
- **외부 도서는 가이드 3부** — 개념 재서술만, 원문 문장·코드 예제 미수록, 열람 페이지 주소를 공개 노트에 남기지 않는다.
