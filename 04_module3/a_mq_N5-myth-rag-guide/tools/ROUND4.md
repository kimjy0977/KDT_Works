## 0. 왜 4바퀴가 필요한가

3바퀴의 수치는 **12점·41청크 시절**에 잰 것이다. 그 뒤 자료가 이렇게 바뀌었다.

| | 3바퀴 당시 | 지금 |
|---|---|---|
| 작품 | 12점 | **982점** |
| 청크 | 41 | **2,978** |
| 신화 | 그리스로마만 | **6종 전부** |

검색이 고르는 15조각의 **성격이 달라졌다**. 후보가 41개일 때와 2,978개일 때 «상위 15개»는 다른 물건이다.
그러므로 3바퀴 결론(**base 유지**)이 지금도 맞는지는 **모른다.** 그게 이번에 잴 것이다.

## 3. 순서

### ① eval-hits 재생성 — **가장 중요** (약 5분)

3바퀴의 `eval-hits.json` 은 **41청크 시절 검색 결과**다. 지금 말뭉치로 다시 뽑아야 한다.

```
로컬 서버를 띄우고 ?evalhook=1 로 열어 tools/capture-hits.js 를 실행한다.
결과는 로컬 수신기로 POST 되어 tools/eval-hits.json 을 덮는다.
```

> ⚠️ **옛 파일을 먼저 백업한다** — `eval-hits-r3.json` 으로. 3바퀴 표를 나중에 다시 읽을 때 필요하다.
> ⚠️ **6신화를 다 불러온 뒤에** 뽑는다. 기본은 그리스로마만 로드되므로, 화면에서 나머지 5신화 «불러오기»를 누르거나 스크립트가 `loadMyth` 를 먼저 돌린다. 안 그러면 **그리스로마만 후보가 되어** 3바퀴와 같은 조건이 아니다.

### ② 세팅 실행 (세팅당 약 10~15분 · 13문항 × 생성 1 + 판정 4)

```bash
python tools/run-variant.py base      # 기준 행 — 반드시 먼저
python tools/run-variant.py prompt
python tools/run-variant.py topk5
```

> `big`(모델 교체)은 3바퀴에서 **명백히 탈락**했다(사실정확 0/7, 답 대신 ID만 뱉음).
> VRAM 4GB 제약도 그대로다. **다시 돌릴 이유가 없다.** 7B급을 올릴 하드웨어가 생기면 그때.

### ③ 자가 검사 — 자부터 확인 (약 15분)

```bash
python tools/run-variant.py base      # 같은 세팅 두 번째
```

`variant-base.json` 두 판본의 **평균 절대차**를 본다.

| 결과 | 뜻 |
|---|---|
| **0.0점** | 3바퀴 때처럼 자가 멀쩡하다. 세팅 비교를 신뢰해도 된다 |
| **0점 초과** | ⚠️ 통제가 깨졌다. **비교를 중단하고** 원인부터 찾는다(온도·검색 고정·모델 버전) |

### ④ 기록

`README.md` 에 새 절 「실험 — 네 바퀴: 자료가 24배가 된 뒤 다시 쟀다」 를 **추가**한다.
표 형식은 3바퀴 절을 그대로 따른다(세팅 / 바꾼 것 / 평균 / 부당거부 / 정당거부 / 사실정확 / 인용).

**사실 정확은 자동 판정이 아니다.** 근거 원문과 사람이 대조한다 — 8강이 요구한 몫이다.

## 4. ★반증 조건 — 무엇이 나오면 무엇을 결론짓나

**미리 정해 둔다.** 결과를 보고 기준을 정하면 어떤 결과든 «좋게» 읽힌다.

| 관찰 | 결론 | 다음 행동 |
|---|---|---|
| 자가 검사 **0.0점 아님** | 측정 실패 | 비교 중단. 통제 조건부터 고친다 |
| base 평균이 3바퀴(**57.9점**)보다 **10점 이상 하락** | 자료를 늘린 것이 **검색 잡음을 키웠다** | 자료를 늘린 게 답이 아닐 수 있다. 신화별 분리 검색을 검토 |
| base 평균이 **±10점 이내** | 자료 규모는 품질에 영향 없음 | 3바퀴 결론 유지. 병목은 여전히 생성 모델 |
| 어떤 세팅도 base 를 **5점 이상** 못 이김 | 3바퀴와 같은 결론 | **base 유지**. 세팅을 바꾸지 않는다 |
| 어떤 세팅이 base 를 **5점 이상** 이기고 **부당 거부도 안 늘어남** | 그 세팅 채택 | 코드에 반영하고 배포. 이유를 README에 |
| 부당 거부가 **늘었는데** 평균이 오름 | ⚠️ 평균에 속은 것 | 채택하지 않는다. 3바퀴 `topk5` 가 그랬다 |

> **5점**을 기준으로 삼는 이유 — 3바퀴에서 `topk5` 가 base 를 **1.2점** 이겼는데 부당 거부가 늘었다.
> 그 정도 차이로 세팅을 바꾸면 잡음을 쫓는 것이다. 자가 검사가 0.0점이어도 **문항 13개의 표본은 작다.**

## 6. 안 하기로 한 것 (미리 적어 둔다)

- **`big` 세팅** — 3바퀴에서 탈락. 하드웨어가 그대로다.
- **문항 추가** — 13문항을 유지한다. 문항을 바꾸면 3바퀴와 비교가 끊긴다. 새 문항이 필요하면 **Q14~ 로 덧붙이고 옛 13개는 그대로** 둔다.
- **자료를 다시 바꾸기** — 실험 도중에 말뭉치를 건드리지 않는다. 4바퀴는 «982점 시점»의 기록이다.
