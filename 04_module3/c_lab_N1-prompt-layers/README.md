# 프롬프트를 «한 층만» 바꿔 보기

> 모듈3 노드1 **5강** 실습 · 김주영 (아이펠 KDT AI 에이전트 1기)

## 무엇을 한 실습인가

**질문을 «고정»하고 한 번에 한 층만 바꿔**, 날것의 출력이 어떻게 달라지는지 파일로 남겨 비교했습니다.

| 시행 | 무엇만 바꿨나 | 결과 파일 |
|---|---|---|
| ① | `system` = *「고객 문의에 정중하게 답한다」* | `01-customer-support.txt` |
| ② | **`system` 만** *「기술 문서 톤으로 답한다」* 로 | `02-technical-documentation.txt` |
| ③ | **대화 이력만** 추가(같은 system) | `03-with-history.txt` |

질문은 셋 다 **「배송일은 언제인가요?」로 동일**합니다.
한 번에 둘 이상을 바꾸면 **무엇이 효과였는지 못 가르기 때문**입니다.

## 두 경로로 각각

| 파일 | 경로 | 비고 |
|---|---|---|
| `messages_lab.py` | **Claude Agent SDK** (`query` / `ClaudeAgentOptions`) | 인증 필요 |
| `ollama_lab.py` | **Ollama** (`llama3.2:1b`) | **완전 로컬 · 키 불필요** |

```bash
python ollama_lab.py      # 로컬만으로 재현됩니다
python messages_lab.py    # Claude Agent SDK 경로
```

## ★결과에서 «의도치 않게» 나온 것

저장된 출력을 그대로 두었습니다. 다듬지 않았습니다.

`llama3.2:1b`(1.2B)의 답이 **한국어·영어·베트남어·러시아어·중국어를 뒤섞어** 냈습니다.

> *"배송일은 following 형식으로 определя됩니다"* · *"5-7 ngày之间 배송"*

**이것도 실습 결과입니다.** 프롬프트 층을 바꾸는 것과 **모델이 그 층을 감당할 수 있는지는 다른 문제**라는 걸
보여 줍니다. 같은 프롬프트를 더 큰 모델에 넣으면 이 현상은 사라집니다.

② 기술 문서 톤에서는 **없는 절차를 5단계로 지어냈습니다**(수리·testing·고정shipping…).
배송일을 모르는 상태에서 「기술 문서 톤」을 요구하니 **형식은 맞추고 내용을 채운** 것입니다.
→ **톤 지시가 «사실 없음»을 덮을 수 있다**는 사례로 남깁니다.

③ 이력을 넣자 앞의 대화를 이어받긴 했지만, 여전히 **문장이 무너집니다.**

## 남긴 이유

출력이 나쁘다고 지우면 **「프롬프트만 바꾸면 된다」는 잘못된 결론**이 남습니다.
층을 바꾸는 실험은 **모델이 그 층을 소화할 수 있을 때만** 의미가 있습니다.
