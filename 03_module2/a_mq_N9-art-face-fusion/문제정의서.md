# 문제 정의서 — "명화의 주인공 되기" 합성 AI

> Main Quest 2 · 김주영(시각디자인)
> (초안 대비 갱신: 실제 구현이 SAM 누끼 대신 **ControlNet + IP-Adapter 전체 재생성**으로 목표를 달성했다. 이를 반영.)

---

## 1. 도메인 설명 (어떤 관심 영역인가)
**미술·명화 감상.** 시각디자인 전공자로서 자세히 아는 관심 영역이다. 사람들은 명화를 늘 "남의 그림, 남의 인물"로만 감상한다. 이걸 **"내가(또는 원하는 인물이) 그 명화의 주인공이 되어 보는" 체험**으로 바꾸는 것이 이 프로젝트의 영역이다. (예: 진주 귀고리를 한 소녀를 모나리자의 자리에)

## 2. 현재의 문제 (지금은 어떻게 하며, 뭐가 번거로운가)
명화에 특정 인물을 그 화풍 그대로 넣으려면 지금은:
1. **포토샵으로 수동 합성** — 인물 누끼 → 명암·색감·붓터치(화풍) 맞추기 → 자연스럽게 녹이기. **수십 분 + 전문 기술.**
2. **비전문가는 사실상 못 한다.** 어설프면 인물이 붕 떠서 어색하다.
3. 기존 "AI 아트 필터"는 사진 전체를 화풍으로만 바꿔줄 뿐, **"바로 그 명화의 그 인물 자리에 인물을 앉히는" 건 못 한다.**

→ 하고 싶은 사람은 많은데 **진입장벽(기술·시간)이 높아** 대부분 포기한다.

## 3. 개선 가설 (AI를 어느 단계에 어떻게)
목표 명화와 넣을 인물을 고르면, AI가 어려운 단계를 대신한다.
- **[구도] ControlNet (Canny)** — 명화의 **포즈·구도·풍경 구조를 조건**으로 고정. (N5 포즈 툴에서 익힌 ControlNet 기술 재사용)
- **[정체성] IP-Adapter** — 넣을 인물의 **외형(얼굴·의상·특징)을 참조로 주입.**
- **[생성] Stable Diffusion** — 위 둘을 조건으로 **명화 화풍으로 인물을 전체 재생성.**

**핵심:** AI를 **"누끼 + 화풍 맞추기 + 합성"** 이라는 제일 어려운 단계에 꽂아, 전문 기술 없이도 수십 초 안에 결과가 나오게 한다.

## 4. 대상 사용자 (누가 도움받나)
- **명화를 좋아하는 일반인** / 자기(또는 특정 인물)를 명화 주인공으로 넣어보고 싶은 사람 (SNS 프로필, 전시 체험, 선물용 등).
- 나 자신(시각디자이너)도 포함.

## 5. 성공 기준 (측정 가능한 기준)
- **시간:** 포토샵 수동 합성(수십 분) → AI **1분 이내**.
- **접근성:** 전문 기술 없이 비전문가가 결과를 얻는가.
- **품질(정성):** 인물이 명화에 **자연스럽게 녹아든** 결과인가(이질감·일그러짐 없는지).
- **비교:** 수동 합성 vs AI, 그리고 AI 방법 3종(face-swap/인페인팅/전체재생성) 비교 + 실패 케이스 정리.

## PoC 범위 (스코프)
- **명화 2점**(모나리자 · 진주 귀고리를 한 소녀, **퍼블릭 도메인**).
- **코어:** ControlNet(구도) + IP-Adapter(정체성) + Diffusion(생성).
- **한계·다음 단계:** 정체성 정확도 강화, 해상도 향상(SDXL·업스케일), **SAM 누끼 결합**(배경·인물 분리 제어), 다인·추상 명화 확장, 웹 데모 배포.

## 모델 선정 근거 (배운 모델 후보 비교)
이 모듈에서 배운 모델들을 "명화에 인물을 **화풍째 합성**한다"는 문제에 대입해 비교했다.

| 후보 모델 | 이 문제에 맞나? | 판정 |
|---|---|---|
| **YOLO** (객체 탐지) | 물체 위치 박스만 줌 → **생성 능력 없음**. 명화 합성과 무관 | ✗ 부적합 |
| **STT · 음성 생성** | 음성 도메인 → 이미지 과제와 무관 | ✗ 부적합 |
| **SAM** (세그멘테이션/누끼) | 인물 분리엔 유용하나, 그것만으론 **화풍 합성·생성 불가**(보조 역할) | △ 보조(이번 미사용) |
| **Diffusion** (이미지 생성) | 명화 화풍으로 인물을 **직접 그려냄** = 문제의 본질 | ✅ **코어 채택** |
| ↳ **+ ControlNet** | 명화의 **구도·포즈를 조건**으로 고정 (모듈2 노드5 포즈툴서 익힘) | ✅ |
| ↳ **+ IP-Adapter** | 넣을 인물의 **정체성(얼굴·의상) 주입** | ✅ |

**결론:** 문제의 본질이 "**생성**"이라 생성 모델인 **Diffusion**이 유일한 코어다. 여기에 구도 제어(ControlNet)·정체성 주입(IP-Adapter)을 얹어 명화 합성에 특화했다. YOLO·STT는 도메인 불일치로 탈락, SAM은 보조 후보로 다음 단계에 결합 예정.
