# 문제 정의서 — AI 패키지 목업 자동 생성 도구

> Main Quest 2 · 김주영(시각디자인) · 초안 v1

---

## 1. 도메인 설명 (어떤 업무·현장인가)
**시각디자인 — 특히 패키지 디자인 시안을 "목업(mockup)"에 얹어 보여주는 작업.**
디자이너는 패키지 시안(라벨·정면 그래픽 등)을 완성하면, 클라이언트 확인용·포트폴리오용으로
실제 제품에 입힌 사실적인 목업 이미지를 만든다. 이 목업 제작이 반복적으로 발생하는 핵심 업무다.

## 2. 현재의 문제 (지금은 어떻게 하고 있으며, 뭐가 번거로운가)
지금은 전부 수작업이다.
1. **알맞은 목업을 따로 찾아야 한다** — 특히 패키지는 형태(파우치·박스·병·튜브)가 다양해
   내 디자인 비율에 딱 맞는 목업을 찾기가 매우 어렵다.
2. **디자인을 목업에 수동으로 넣어야 한다** — 포토샵 스마트오브젝트 등에 일일이 삽입.
3. **사이즈가 안 맞으면** 디자인을 수정하거나, 아예 다른 목업을 처음부터 다시 찾아야 한다.

→ 시안 하나 확인하는 데 **약 10~20분**, 배리에이션이 여러 개면 그만큼 배가된다.
   창작이 아니라 "찾고·넣고·맞추는" 반복 노가다에 시간이 샌다.

## 3. 개선 가설 (AI를 어느 단계에 어떻게 넣으면 나아지나)
디자인 이미지 하나를 올리면, AI가 **"면 인식 + 자동 배치"** 단계를 대신한다.
- **[코어] SAM(세그멘테이션)** — 목업 속 **인쇄 가능 면(파우치 정면)을 자동으로 인식**하고
  그 면의 모양·크기에 맞춰 내 디자인을 **자동 워프·삽입**한다.
  → "수동 삽입"과 "사이즈 안 맞음" 문제를 한 번에 해결(어떤 비율의 디자인이든 면에 맞춰 들어감).
- **[추가] Diffusion 인페인팅** — 목업 장면 자체를 생성해, "알맞은 목업 찾기" 문제까지 없앤다.

**핵심:** AI를 창작이 아니라 **반복 잡업(면 찾기·크기 맞추기·삽입)** 에 꽂는다.

## 4. 대상 사용자 (누가 가장 도움받나)
- 패키지/시각 디자이너(프리랜서·인하우스) — 클라이언트에게 시안을 빠르게 보여줘야 하는 사람.
- **나 자신** — 목업 적용이 가장 귀찮은 반복 작업이라 직접 수혜자다.

## 5. 성공 기준 (측정 가능한 기준)
- **시간 단축:** 목업 1개 수작업(약 10~15분) → PoC로 **30초~1분** 목표.
- **품질(정성):** 테스트 디자인 10개 중 **"바로 쓸만한" 결과 비율**(예: 7/10 이상).
- **사이즈 대응:** 서로 다른 비율의 디자인 5개를 넣어도 면에 맞게 들어가는가(성공/실패 건수).
- **비교:** 수작업 결과 vs AI 결과를 나란히 놓고 차이 설명 + 실패 케이스 정리.

## PoC 범위 (스코프) — 작게 증명하고 크게 확장
- **대상: 파우치 정면 1종** (평평한 면부터 — AI 성공률이 가장 높은 지점).
- **코어:** SAM 면 인식 + 디자인 자동 삽입.
- **추가 시도:** Diffusion으로 목업 장면 생성.
- **한계·다음 단계:** 박스·병·튜브 등 곡면 패키지, 목업 자동 추천, 여러 배리에이션 일괄 생성.
  → "파우치로 증명되면 다른 패키지로 확장" 이 다음 단계 제안서의 뼈대.

## 사용 모델 요약
| 역할 | 모델/기법 | 비고 |
|---|---|---|
| 면 인식·자동 삽입 (코어) | **SAM** + 원근 워프(OpenCV) | 이번 모듈 학습 모델 |
| 목업 장면 생성 (추가) | **Stable Diffusion 인페인팅** | N5에서 익힌 기술 재사용 |
