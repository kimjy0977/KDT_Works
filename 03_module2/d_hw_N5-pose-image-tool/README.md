# 원하는 포즈로 이미지 만드는 도구

지정한 포즈(OpenPose 스켈레톤)를 그대로 따라 하는 **전신 서있는 인물** 이미지를 만드는 도구.

## 도구 설명
전신 OpenPose 스켈레톤을 **ControlNet 조건**으로 넣어, **Stable Diffusion 1.5**가 그 자세의 서로 다른 인물(옷차림)을 생성한다. 프롬프트만 바꿔도 **자세는 유지**된다.

## 사용법
1. `pose_tool.ipynb`를 Colab에서 연다 (GPU 권장) 또는 로컬에서 실행.
2. 셀을 **위에서 아래로 순서대로** 실행한다.
3. 결과 이미지는 `samples/` 폴더에 저장된다 (`pose_01.png`, `output_01.png`, `output_02.png`).
4. 다른 포즈를 쓰려면 참조 스켈레톤/사진 URL을 바꾼다.

## 테스트 결과
| 입력 포즈 | 프롬프트 | 결과 | 포즈 반영 |
|---|---|---|---|
| pose_01 (전신 서있는 스켈레톤) | 캐주얼 남자 (운동화) | output_01.png | ✅ 전신·같은 자세 |
| pose_01 (동일) | 정장 남자 (구두) | output_02.png | ✅ 전신·같은 자세, 옷만 다름 |

- **같은 포즈 + 프롬프트만 변경:** 두 결과 모두 **머리부터 발끝까지 전신**이 같은 서있는 자세로 나오고, 옷차림(캐주얼↔정장)만 바뀜 → 입력 포즈가 그대로 반영됨.
- **재현성:** `seed=42`를 고정해 같은 실행 환경에서 결과의 반복성을 높였다. CPU(`float32`)와 GPU(`float16`)처럼 장치·정밀도·라이브러리 버전이 달라지면 픽셀 단위로 동일한 이미지는 보장되지 않는다.

## 다리가 잘리지 않게 한 방법 (핵심 노하우)
SD1.5는 인물을 상반신으로 잘라 그리는 버릇이 있어, 그냥 넣으면 다리·발이 잘린다. 아래로 해결:
1. **출력 세로 프레임** (512×768) — 정사각형이면 아래가 잘림.
2. **스켈레톤을 프레임 위쪽에 작게 배치**(아래 여백 크게) → 발이 프레임 안으로.
3. **ControlNet 강도 1.15**로 자세를 더 강하게 따르게.
4. 프롬프트 "full length, head to shoes, feet on the floor" + 네거티브 "cut off, missing feet".

## 사용 모델
- 생성: `stable-diffusion-v1-5/stable-diffusion-v1-5` + ControlNet `lllyasviel/sd-controlnet-openpose`
- 스케줄러: UniPCMultistepScheduler, steps=20, seed=42
