# 류승완

분류: 1973년 출생, 20세기 대한민국 사람, 21세기 대한민국 사람, 대종상 감독상 수상자, 대한민국 영화대상 수상자, 대한민국의 개신교도, 대한민국의 남자 배우, 대한민국의 남자 영화 배우, 대한민국의 뮤직 비디오 감독, 대한민국의 영화 각본가, 대한민국의 영화 감독, 대한민국의 영화 제작자, 대한민국의 이라크 전쟁 반전 운동가, 디렉터스 컷 시상식 수상자, 맥스무비 최고의 영화상 수상자, 백상예술대상 영화부문 감독상 수상자, 백상예술대상 영화부문 대상 수상자(작), 부산영화평론가협회상 수상자, 부일영화상 수상자, 살아있는 사람

류승완(柳昇完, 1973년 12월 15일~)은 대한민국의 영화 감독이자 영화 배우이다.
