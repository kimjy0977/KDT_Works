# LA 컨피덴셜

분류: 1951년을 배경으로 한 영화, 1952년을 배경으로 한 영화, 1953년을 배경으로 한 영화, 1997년 영화, 네오누아르, 로스앤젤레스를 배경으로 한 영화, 리젠시 엔터프라이즈 영화, 마피아 영화, 모든 토막글 문서, 미국 국립영화등기부 등재 영화, 미국의 범죄 드라마 영화, 미국의 범죄 스릴러 영화, 미국의 소설을 바탕으로 한 영화, 미국의 스릴러 드라마 영화, 범죄 영화에 관한 토막글, 살인자를 소재로 한 영화, 수사 영화, 아카데미 각색상 수상작, 아카데미 여우조연상 수상작, 영국 아카데미상 수상작, 영어 영화 작품, 영어 표기를 포함한 문서, 워너 브라더스 영화, 위키데이터 속성 P1273을 사용하는 문서, 위키데이터 속성 P154를 사용하는 문서, 위키데이터 속성 P227을 사용하는 문서, 위키데이터 속성 P244를 사용하는 문서, 위키데이터 속성 P268을 사용하는 문서, 위키데이터 속성 P9984를 사용하는 문서, 해결되지 않은 속성이 있는 문서

《LA 컨피덴셜》(영어: L.A. Confidential)는 1997년에 개봉한 영화이며 1990년에 나온 제임스 엘로이의 동명소설을 영화화하였다. 71회(1998년) 아카데미 시상식에서 9개 부문(작품상, 감독상, 여우조연상, 각색상, 편집상, 촬영상, 음향상, 음악상, 미술상) 후보에 올랐고 이 중에서 여우조연상(킴 베이싱어)과 각색상을 수상하였다.
