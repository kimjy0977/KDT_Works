# 연상호

분류: 1978년 출생, 20세기 대한민국 사람, 21세기 대한민국 사람, 곡산 연씨, 대한민국의 애니메이션 제작자, 대한민국의 영화 각본가, 대한민국의 영화 감독, 들꽃영화상 수상자, 백상예술대상 영화부문 신인감독상 수상자, 살아있는 사람, 상명대학교 동문, 숭실고등학교 동문, 애니메이션 영화 감독

연상호(延尚昊, 1978년 12월 25일~)는 대한민국의 영화 감독, 애니메이션 감독이다.
