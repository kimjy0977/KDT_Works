# 시카리오: 암살자의 도시

분류: 2015년 영화, 뉴멕시코주를 배경으로 한 영화, 뉴멕시코주에서 촬영한 영화, 델타 포스를 소재로 한 영화, 드니 빌뇌브 감독 영화, 멕시코를 배경으로 한 영화, 모든 토막글 문서, 미국의 미스터리 영화, 미국의 범죄 드라마 영화, 범죄 영화에 관한 토막글, 애리조나주를 배경으로 한 영화, 애리조나주에서 촬영한 영화, 영어 영화 작품, 영어 표기를 포함한 문서, 위키데이터 속성 P1273을 사용하는 문서, 위키데이터 속성 P154를 사용하는 문서, 위키데이터 속성 P1695를 사용하는 문서, 위키데이터 속성 P244를 사용하는 문서, 위키데이터 속성 P373을 사용하는 문서, 위키데이터 속성 P436을 사용하는 문서, 위키데이터 속성 P7293을 사용하는 문서, 위키데이터 속성 P950을 사용하는 문서, 해결되지 않은 속성이 있는 문서

《시카리오: 암살자의 도시》(영어: Sicario)는 2015년 공개된 드니 빌뇌브 감독의 범죄 영화이다. 에밀리 블런트, 베니치오 델 토로 등이 출연한다.
