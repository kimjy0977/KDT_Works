# 강형철

분류: 1974년 출생, 20세기 대한민국 사람, 21세기 대한민국 사람, 대종상 감독상 수상자, 대한민국의 영화 각본가, 대한민국의 영화 감독, 백상예술대상 영화부문 감독상 수상자, 백상예술대상 영화부문 시나리오상 수상자, 살아있는 사람, 올해의 영화상 수상자, 용인대학교 동문, 제주특별자치도 출신, 청룡영화상 신인감독상 수상자, 한국영화평론가협회상 수상자

강형철(1974년~)은 대한민국의 영화 감독, 영화 각본가이다.
