# 낵 앤 하우 투 겟 잇

분류: 1965년 영화, 1965년 코미디 영화, 글로벌세계대백과를 인용한 문서, 런던을 배경으로 한 영화, 리처드 레스터 감독 영화, 영국의 로맨틱 코미디 영화, 영국의 섹스 코미디 영화, 영국의 흑백 영화, 영어 영화 작품, 영어 표기를 포함한 문서, 위키데이터 속성 P1273을 사용하는 문서, 해결되지 않은 속성이 있는 문서, 황금종려상 수상작

《낵 앤 하우 투 겟 잇》(영어: The Knack ...and How to Get It)은 1965년에 개봉한 영국의 코미디 영화로, 리처드 레스터가 연출하였다. 마이클 크로퍼드, 리타 터싱엄, 레이 브룩스, 도널 도널리 등이 출연하였고, 오스카 루언스타인 등이 제작에 참여하였다.


== 줄거리 ==
시골 처녀(리타 터싱엄 분)가 런던에 상경하여 젊은 초등학교의 교사(마이클 크로퍼드 분)와 알게 된다. 교사는 눈치가 없는 내성적이고 멍청한 사나이인데, 여자들한테 전혀 인기가 없는 것을 항상 고민하고 있었으므로 그녀와 알게 되어 크게 기뻐한다. 그런데 인기가 있는 미남이 그녀를 가로채려고 한다. 그러나 그렇게는 못하리라고 교사는 발분하여 드디어 그녀의 마음을 사로잡는다.

== 감상 ==
줄거리는 매우 단순하나 표현이 지극히 꼼꼼한 슬랩스틱 코미디(난장판 희극)의 걸작이다. 그렇다고는 하지만 너무나 표현이 지나치게 비약하여, 웃음보다는 오히려 어처구니가 없어져 버릴 정도이다. 텔레비전 감독 출신인 리처드 레스터 감독은 CM 필름류(流)의 엉뚱하게 비약하는 영상(映像)의 어리석음 가운데 현대적인 시정(詩情)을 엮어 보였다. 인기 있는 남자는 여자를 몇 백 명이라도 세워 놓고 한쪽서부터 모조리 키스를 한다. 노이로제의 세계이며 만화의 세계이다. 그리고 최후에 일말(一抹)의 비애(悲哀)가 남는다.
