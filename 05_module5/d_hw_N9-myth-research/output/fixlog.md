> ⚠**손으로 옮긴 값이다** — 자동으로 찍은 것이 아니다. 최종 REPORT 는 `ablation.json` 에서 찍는다.

## 1회차 — 2026-09-23 · 고치기 «전»

```
근거율       71.4%   (문장 35개)
★허위 인용      2     ← 경보가 울렸다
읽고 안 쓴      2건    그리스 신화 · 길가메시

```

### ★경보를 «열어 보니» 다른 사고였다

```
읽음   길가메시 서사시 · 길가메시
인용   길가미시 서사시 · 길가미시     ← ★한 글자 오타
```

**안 읽은 문서를 지어낸 것이 아니라, 읽은 문서를 «틀린 이름»으로 불렀다.**
내용은 맞았다. 채점기가 「안 읽은 문서」로 봤을 뿐이다.

⇒ 요건이 이름 붙인 흔한 사고 ①「지표가 좋아진 줄 알았는데 문장 분리 규칙이 바뀐 것」의
**반대 얼굴**이다 — 나빠진 줄 알았는데 표기 흔들림이었다.

## 고친 것 둘

### ① 지표를 «느슨하게» 하지 않고 «갈랐다»

```
허위 인용    읽은 것과 «닮지도 않은» 이름  → 환각.   경보 · 0이어야 한다
표기 흔들림  읽은 것과 «거의 같은» 이름    → 오타.   프롬프트 문제
```

⛔둘을 합쳐 통과시키면 진짜 환각을 놓친다. **대응이 정반대라서 갈라야 한다.**

### ★판정을 «세 번» 고쳤다 — 매번 재 보고 고쳤다

```
1차 비율(SequenceMatcher) ≥ 0.8
    ⛔길가미시 vs 길가메시 = 0.75 — ★정작 그 사례를 못 잡는다
    ⛔0.75 로 낮추면 오시리스 vs 오시리스 신화(0.73)까지 같다고 한다
      (코퍼스에 ★둘 다 있는 다른 문서다)
    ⇒ 짧은 이름에 비율은 가혹하다. 버렸다

2차 편집거리 ≤ 1 · 길이차 ≤ 1
    ✅길가미시 vs 길가메시        거리 1 → 오타
    ✅오시리스 vs 오시리스 신화    거리 3 → 다른 문서
    ✅그리스 신화 vs 로마 신화     거리 3 → 다른 문서
    ⛔그런데 ★이자나기 vs 이자나미 = 거리 1 — «다른 신»을 합친다

3차 + 안전장치 — 코퍼스에 «실재하는» 제목이면 오타로 보지 않는다
    실재하는 제목을 인용했으면 그건 «안 읽고 인용한» 것 = ★진짜 허위다
    코퍼스에 «없는» 이름일 때만 오타 후보로 본다
```

★**요건 「설명이 한 줄로 안 되는 지표는 버립니다」** — 「한 글자만 틀렸으면 오타」는
한 줄로 끝난다. 「0.8 이상」은 그렇지 않다. 그래서 1차를 버렸다.

### ② 프롬프트에서 «애초에» 막았다

```
추가  ★★제목은 위 목록에서 «글자 그대로 복사»하세요. 한 글자도 바꾸지 마세요.
      실측 사고 — 「길가메시」를 「길가미시」로 적어 허위 인용 2건으로 찍혔습니다.
```
노드8 에서 근거율 0% → 75% 로 올린 것도 프롬프트였다. 여기선 목록을 줬는데도
오타가 났으므로 한 겹 더 걸었다.

## ⚠ 단정하지 않는다 — 1회 측정이다

노드8 REPORT §6 에 **「1회 측정이 나를 두 번 속였다」**고 적었다.
여기서 「고쳐서 0이 됐다」고 쓰면 **같은 실수**다.

```
지금 아는 것    고친 뒤 «한 번» 돌렸더니 0 이었다
모르는 것       ★이 0 이 «안정적인가». 오타는 확률적으로 난다
해야 할 것      ablation --runs 3 이상에서 표기흔들림 열을 함께 본다
```

★그리고 **노드8 의 3회 결과도 4회차에 깨졌다**(solo 근거율 21.7% → 16.3%).
「±1.5 로 안정적」이라고 적은 것이 **3회로는 부족했다**는 뜻이다.
⇒ 이 프로젝트에서는 **회차를 더 돌리고, 폭을 함께 적는다.**
