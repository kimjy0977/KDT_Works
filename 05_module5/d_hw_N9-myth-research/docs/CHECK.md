## 14. README 와 REPORT 의 쓰임 — 하네스 §6-10

```
README   «안내판»  무엇이고 · 어떻게 돌리고 · 어디를 보면 되나 · 피어리뷰 안내
REPORT   «내용»    왜 그렇게 했나 · 무엇을 쟀나 · 뭐가 틀렸나 · ★화면 캡처
```

★**두 문서 다 «맨 위»에 서로를 가리키는 줄을 둡니다.** 채점자는 README 부터 열기
때문에, 링크가 본문 아래에 묻히면 REPORT 를 안 보고 채점합니다.

★**화면 캡처는 REPORT 에 둡니다.** 요건이 「데모 설계: 신경 쓴 부분, **화면 캡처와
함께**」라고 REPORT 쪽을 가리킵니다. README 에도 한 장 두되 **역할이 다릅니다** —
README 는 「이런 화면입니다」, REPORT 는 「이래서 이렇게 짰습니다」.

⛔모듈·이름·날짜를 인용구(`>`)로 쓰지 않습니다 — **굵은 글씨 한 줄**입니다.

⛔성능 수치를 **두 문서에 손으로** 적지 않습니다 — `sync_numbers.py` 가
`<!-- ABL:START -->` 같은 표식 사이를 **찍어냅니다.**
(이번에도 한 번 샜습니다 — 「0.6%p」를 손으로 박아 뒀다가 회차가 바뀌자 거짓말이
됐습니다. 찍어내는 블록 안에 손으로 쓴 수치를 두면 안 됩니다.)
