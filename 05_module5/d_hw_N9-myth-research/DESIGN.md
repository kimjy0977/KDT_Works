# DESIGN — 측량 도면 (Survey Drawing)

이 파일이 **디자인 결정의 유일한 출처**입니다. `ui.py` 는 여기 적힌 값을 코드로 옮긴 것뿐입니다.
(`config.json` 이 도메인 값의 유일한 출처인 것과 같은 이유 — 같은 것을 두 군데서 정하면 갈립니다.)

---

## 왜 «다시» 만들었나 — 앞 판이 AI 클리셰였습니다

1판은 사이드바 + 지표 4칸 + 탭 3개였습니다. **색만 바꾼 리스킨**이라 버렸습니다.
2판은 「성좌 필사본」 — 다크 배경 + 명조 + 금박 + 올캡스 라벨.
**조사해 보니 그게 더 나쁩니다.** 2026년 AI 생성 UI의 표식 16개 중 **9개**를 밟았습니다.

```
#5  영구 다크모드 + 올캡스 섹션 라벨            → 했다
#7  그라디언트 남발                            → 했다 (radial 여러 겹)
#8  컬러 글로우·컬러 그림자                     → 했다
#10 H1 바로 위 배지                            → 했다 (eyebrow)
#11 카드 왼쪽 컬러 보더 ← ★가장 확실한 표식      → 했다
#12 아이콘 얹은 «동일한» 카드 반복               → 했다 (계기판 4칸)
#13 1·2·3 번호 단계                            → 했다
#14 스탯 배너 줄                               → 했다
#16 올캡스 제목·라벨                            → 했다
```

★**그리고 「안티-슬롭」 조언 자체가 새 클리셰가 됐습니다** —
*크림 배경 + Instrument Serif + 세이지 그린*. **다크+명조+금박도 같은 부류**입니다.

⇒ 그래서 **「무엇을 피하나」가 아니라 「이 내용에 무엇이 맞나」**로 다시 정했습니다.

## 컨셉 — 측량 도면

이 시스템이 하는 일은 **자료를 구역으로 나눠 맡기고, 누가 무엇을 읽었는지 추적하는 것**입니다.
그건 **측량**입니다. 측량 도면의 문법을 그대로 씁니다.

```
도면은 흰 종이에 그린다            → 밝은 배경. ⛔다크모드 안 씀
도면에 그림자는 없다                → box-shadow 0. 선과 여백만
도면은 «선»으로 구분한다            → 카드 대신 ★헤어라인 괘선
도면의 범례는 색이 아니라 «선 모양»  → 조사관 4명을 dash 패턴으로 가른다
도면에서 붉은색은 «검토 표시»다      → 강조색 ★단 하나. 근거·경보에만
```

## 토큰

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `paper` | `#F4F2ED` | 배경. ⛔순백(#FFF) 아님 — 종이의 따뜻함 |
| `ink` | `#16171A` | 본문. ⛔순흑 아님 |
| `ink60` | `#5B5D63` | 보조 |
| `ink40` | `#8A8C92` | 캡션 |
| `rule` | `#D8D4C9` | ★괘선 — 이 디자인의 주 구조 요소 |
| `rule2` | `#EBE8E0` | 옅은 괘선 |
| `mark` | `#A33420` | ★강조색 **단 하나**. 근거·경보·검토 표시 |
| `markbg` | `#F6E4DF` | 경보 바탕 (보더 아님 — ★#11 회피) |

**색은 여덟 개뿐이고, 유채색은 `mark` 하나입니다.**
조사관 구분은 색이 아니라 **선 모양 + 위치 + 번호**로 합니다(규칙 `color-not-only` 도 만족).

## 타이포

```
본문·제목   IBM Plex Sans KR   ★고딕. 한글 글리프가 «진짜»로 있다
수치·코드   IBM Plex Mono      tabular figures — 자릿수가 안 흔들린다
```

⛔**Inter · Geist · Space Grotesk · Instrument Serif 를 안 씁니다** — 전부 AI 기본값 목록에 있습니다.
IBM Plex 는 **엔지니어링 도큐먼트용으로 만들어진** 서체라 도면 컨셉과 맞고,
AI 생성물에서 거의 안 나옵니다.

```
제목   600 · 28px · letter-spacing -0.02em
소제목 600 · 15px
본문   400 · 14.5px · line-height 1.75
캡션   400 · 12px
수치   500 · Mono · tabular
```

⛔**올캡스 라벨을 안 씁니다**(#16). 라벨은 **문장 대소문자**입니다.

## 레이아웃

```
⛔가운데 정렬 히어로 없음 (#9)      → 왼쪽 정렬. 제목 옆에 수치가 «붙어» 있다
⛔H1 위 배지 없음 (#10)            → 배지 자체를 안 씀
⛔스탯 배너 줄 없음 (#14)          → ★수치를 «문장 안»에 넣는다
⛔동일 카드 반복 없음 (#12)        → 블록마다 «다른» 모양. 지도·괘선·본문
⛔①②③ 번호 단계 없음 (#13)        → ★지도가 «과정» 자체다
⛔탭 없음                          → 한 화면에 이어진다. 탭은 관계를 감춘다
⛔사이드바 아이콘 없음 (#15)        → 설정은 접힌 줄 하나
그림자 0 · 그라디언트 0 · 글로우 0
```

**세로 리듬** — 8px 배수. 블록 사이는 괘선 하나(1px `rule`)로만 나눕니다.

## 글쓰기

AI 티의 절반은 **글**에서 납니다.

```
⛔「~를 통해 인사이트를 제공합니다」 같은 빈 말
⛔모든 항목에 이모지 불릿
⛔감탄 · 과장 («놀랍게도», «혁신적인»)
✅수치를 «문장 안»에 — 「42건 중 9건만 손이 닿았습니다」
✅모르는 것은 모른다고 — 「잡음이 차이보다 커서 못 가릅니다」
✅짧은 평서문. 주어를 생략하지 않는다
```
