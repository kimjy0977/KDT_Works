## 왜 MYTH 프로젝트 자료를 «안» 쓰나 — 디렉터 보고 내용

주영님이 「신화를 주제로 하면 적절한가」를 물으셨고, **주제는 좋은데 자료 출처는
바꾸는 쪽**을 권했습니다. 그 판단의 근거입니다.

```
MYTH 자료는 «수집된 것»이 아니라 ★«쓰인 것»이다
  참고문헌 · 4개 언어 직접 인용 · 학술적 유보가 붙은 비교 항목까지 정리돼 있다
  ⇒ ★에이전트가 할 일이 이미 끝나 있다
```

**노드8 의 제일 큰 결과가 죽습니다.** 그 실습의 결론은
「혼자 21.7% vs 팀 72.3%(3.3배)」였는데, **자료가 이미 정리돼 있으면 혼자서도 잘합니다.**
대조가 사라지면 남는 건 「잘 됐습니다」뿐입니다.

그리고 하네스 §B-2 — 타 프로젝트 자산을 공개 레포에 싣게 됩니다.

⇒ **위키에서 직접 모읍니다.** 정리 안 된 것을 정리하는 게 이 과제입니다.

## ★이 코퍼스가 노드8 것과 «다른» 점 — 축이 둘이다

```
노드8 (근대사)   축이 하나 — «시간». 절을 나누면 대체로 시기가 갈렸다
★신화           축이 둘   — «주제» × «문화권» 이 가로지른다

   절을 주제로 나누면     → 조사관이 문화권을 가로질러 읽어야 한다
   절을 문화권으로 나누면  → 주제를 가로질러 읽어야 한다
```

⇒ **같은 예산으로 «나누는 방식»을 바꿔 가며 견줄 수 있습니다.**
노드8 에서 못 한 `--full`(폭 4절×2건 vs 깊이 2절×4건)이 **여기서는 의미를 갖습니다.**

## ★수집하면서 잰 것 — 「주제 문서가 얇다」

첫 시도에서 47개 중 **17개가 빠졌습니다.** 「없다」가 아니라 대부분
**이름이 다르거나 넘겨주기**였습니다. `probe_titles.py` 를 만들어 **찾아서 쟀습니다.**

```
주몽      → 동명성왕      저승   → 내세
홍수 신화  → 대홍수 신화    북유럽 신화 → 노르드 신화
바리데기   → 바리공주      힌두 신화  → 인도 신화
```

그리고 **이것이 더 중요합니다** —

```
「주제」 문서   창조 신화 2,070바이트 · 트릭스터 2,331 · 중국 신화 666
                영웅의 여정 535 · 이집트 신화 1,316   ← ★전부 토막글
「문화권·개별」  오시리스 신화 66,685 · 고대 이집트 종교 72,946
                호루스 53,644 · 영웅 45,223 · 대홍수 신화 42,532
```

⇒ ★**한국어 위키에서 「주제」로 절을 나누면 «문서»가 아니라
«문화권 문서 안의 부분»을 읽어야 합니다.** 조사관이 한 문서를 읽고
**자기 절에 쓸 대목만 골라내는** 일이 노드8 보다 어렵습니다.
이게 이 코퍼스의 **진짜 난이도**이고, 격리(요약만 올리기)가 **더 위험한** 자리입니다 —
잘못 요약하면 위층에서 복구할 방법이 없습니다.

⛔**추측으로 메우지 않았습니다.** 「아마 노르드 신화겠지」로 채웠으면
맞았겠지만, 「저승 → 내세」·「바리데기 → 바리공주」는 못 맞혔을 것입니다.
