## ★반드시 알고 계셔야 할 것 둘

### 1. 규칙 라우터 0.975 는 «오염된» 숫자입니다

오분류를 **보고** 키워드를 고쳐 만들었습니다. 한때 **1.000** 까지 갔습니다.
퍼실이 「평가셋을 프롬프트에 넣지 마세요」라고 한 것과 **같은 종류의 누수**입니다.

```
어제 모두몰   규칙 0.677 → LLM 0.911   (LLM 이 +0.234)
오늘 내 것    규칙 0.975 → LLM 0.878   (LLM 이 −0.097)  ← ★뒤집혔다
```

⇒ **발표할 때 LLM 점수(0.878)를 앞세우고, 규칙 점수는 «과적합»이라 밝힙니다.**

### 2. ② 점수가 «내려간» 수정이 있습니다

```
기준선           9/15 (60.0%)   한자 섞임 54자
언어 고정 후      8/15 (53.3%)   한자 섞임  0자   ← 목적은 달성
```

답변에 중국어가 섞여 나오던 것을 고쳤더니 **통과가 1건 줄었습니다.**
1건은 폭 안일 수 있어 «악화»라 단정할 수 없고,
**지표가 못 보는 품질**이 있다는 뜻이기도 합니다.
