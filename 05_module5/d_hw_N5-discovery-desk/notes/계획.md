## 무엇을 만드나

**「발견 데스크」** — 우주·고고학·고생물 질문에 **확실성 등급과 함께** 답하는 에이전트.

### 노드4 → 노드5 대응

| 모두몰 (노드4) | 발견 데스크 (노드5) |
|---|---|
| 상품·주문 문의 | 과학 질문 |
| 5 라우트 | `SPACE` · `ARCHAEO` · `PALEO` · `CONCEPT` · `OTHER` |
| 어드민 조회 도구 9개 | 기사 검색 · 사실카드 · 연대 조회 · 용어 사전 · 출처 조회 |
| 상담원 업무 매뉴얼 | **「과학 소통 원칙」** — 직접 쓴다 |
| 가드레일: 출처 없는 숫자 | **확실성 등급을 잘못 말하는 것** |

### ★이 프로젝트의 «이유» — 모두몰에 없는 문제

```
배송비 2,500원은 «확정»이다.   그런데 과학의 숫자는 «추정»이다.

[정설]  널리 합의된 것              지구 나이 45.4억 년
[추정]  오차 범위가 있는 것          공룡 멸종 6,600만 년 전
[논쟁]  학계가 갈리는 것
[신설]  ★최근 발표 — 아직 검증 안 됨   ← 노드3 이 모으는 «바로 그것»
```

노드3 은 **48시간 이내** 뉴스를 모은다. 그건 **아직 검증 안 된 발표**다.
⇒ 「이건 지난주 발표라 아직 확인되지 않았습니다」라고 **말할 줄 알아야 한다.**

⇒ 그래서 가드레일이 **「숫자에 출처가 있나」가 아니라 「확실성을 제대로 말했나」**를 본다.
