## 한 줄

우주·고고학·고생물 질문에 **확실성 등급과 함께** 답합니다.
「6,600만 년 전」은 **[추정]**, 「지난주 발표」는 **[신설]** — 둘을 같은 말투로 말하지 않습니다.
LangGraph로 지었고, **OpenAI 키 없이 로컬 Ollama(`qwen2.5:7b`)** 로 돕니다.

## 왜 이걸 만들었나 — 모두몰에 «없던» 문제

노드4(모두몰)의 「배송비 2,500원」은 **확정값**입니다. 숫자만 맞으면 답이 맞습니다.
그런데 **과학의 숫자는 대부분 «추정»**입니다.

```
[정설]  널리 합의       지구 나이 45.4억 년
[추정]  오차가 있다     공룡 멸종 6,600만 년 전
[논쟁]  학계가 갈린다   티라노사우루스 깃털 분포
[신설]  ★최근 발표 — 아직 검증 안 됨
```

⇒ 여기서 틀리는 방식은 «숫자를 지어내는 것»만이 아닙니다.
**맞는 숫자를 «틀린 확신»으로 말하는 것**이 더 자주, 더 조용히 일어납니다.
「지난주 발표」를 「밝혀졌습니다」라고 쓰는 순간 [신설]이 [정설]로 둔갑합니다.
숫자는 하나도 안 틀렸는데 답변은 틀렸습니다.

**⇒ 그래서 가드레일이 「숫자에 출처가 있나」가 아니라 「확실성을 제대로 말했나」를 봅니다.**

## 파이프라인

```
질문
 ↓
① 라우팅    SPACE / ARCHAEO / PALEO / CONCEPT / OTHER
 ↓
② 조회      get_fact       기준 사실 카드 25장  → [정설][추정][논쟁]
            search_article 기사 72건          → [신설] (72시간 이내)
            get_article · get_term · list_recent
 ↓
③ 답변      조회 결과에만 근거 · 확실성 등급을 붙여서
 ↓
④ 가드레일   출처 없는 수치 · ★확실성 단정 · 답하면 안 되는 것
```

**지식원이 둘인 이유** — 모두몰은 「매뉴얼 고정값」과 「어드민 조회」로 깔끔히 갈립니다.
그런데 「티라노사우루스 깃털」은 **정설도 있고 이번 주 발표도 있습니다.**
둘을 «함께» 말하되 등급을 구분해야 해서 지식원을 둘로 뒀습니다.

## 돌려보기

```bash
# 환경 — 노드4 venv 를 그대로 씁니다 (옮기면 .venv 가 깨집니다)
PY=../c_lab_N4-routing-grounding/modumall-agent/.venv/Scripts/python.exe

cd desk
$PY 10_collect.py --hours 72      # 지식원 수집 (RSS 14곳)
$PY 11_filter.py --write          # 주제 밖 거르기 + 라우트 재배정
$PY 20_router.py --mode rule      # ① 규칙 기준선
$PY 20_router.py --mode llm       # ① LLM
$PY 30_answer.py --ask "공룡은 언제 멸종했나요"
$PY 30_answer.py --eval           # ② 전체 채점

# ★검사 — 만들면서 계속 돌립니다
$PY 99_audit.py                   # 산출물 전수 감사 (건수는 스크립트가 찍는다)
$PY score_desk.py --self          # 채점기 자기 검증
$PY guard_desk.py --audit         # 가드레일 두 축
$PY 12_eval_search.py             # 검색 채점
```
