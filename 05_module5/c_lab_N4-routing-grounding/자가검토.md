## H. ★회고 4편을 읽고 «다시» 채점한다 (2026-09-16 저녁)

### H-1. ★「내가 유일하게 찾았다」고 믿은 것 대부분을 «남들도» 찾았다

### H-2. 그래서 «아직» 내 것인 것 — 셋뿐이다

```
1  router.py:50 이 config 의 CONF_THRESHOLD 를 덮어쓴다 → 6강 더해보기 3 이 «실행 불가»
2  eval 120건에 OTHER 정답 0건 → 지표 해킹 구조. 매번 outscope 병행 측정
3  모델 크기 x 프롬프트 «교호작용» — 2B +0.279 vs 7B +0.014
   (다른 분들은 전부 API 모델이라 이 비교를 할 수 없다)
```

★3번은 **키가 없어서 생긴 제약이 오히려 만든 것**이다.
  이정은님도 로컬을 시도했다가 「150초 초과로 멈춤」으로 포기하고 Gemini 로 갔다.

### H-3. ★남에게서 «가져와» 실제로 올린 것

| 출처 | 무엇 | 결과 |
|---|---|---|
| 채원님 | 금액은 숫자로 · 조회 결과의 «그 단어»를 | 답변규칙 v2 → **18.8% → 31.2%** |
| 이정은님 | 역방향 가드레일(아이디어만 있던 것) | **구현 + 오탐 24/25 → 3/25** · 「기계적으로는 안 된다」를 실측 |

| 만영님 | 반복 측정 폭 | `--repeat N` 신설 → **배치 안 폭 0.000** (만영님 관찰 재현) |

★**이정은님 것만 «효과 0»** 이었다 — 정밀도 88% · **재현율 9%**.
  그런데 그 실패가 **오늘 가장 값진 발견**이었다:
  나는 오탐만 재고 **재현율을 안 쟀다.** 규칙을 좁힐 때마다 「오탐이 줄었다」고
  세 번 판단하면서, **잡아야 할 것도 같이 놓치고 있다는 걸 볼 «자»가 없었다.**
  ⇒ 검사기 실수 «여섯째»인데, 앞의 다섯과 성격이 다르다 —
    **틀린 값을 낸 게 아니라 «옳은 값을 반쪽만» 냈다.** 이게 더 잡기 어렵다.

⇒ ★**넷 다 «남이 준 것»이다.** 그리고 **오늘 ②를 처음 움직인 것(+12.4%p)도 그중 하나**다.
  하루 종일 혼자 만든 v2·v3·v4 가 7B 에서 벌어들인 건 **+0.014** 였다.
