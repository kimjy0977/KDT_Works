**v2 「전시 도록 · 큐레이토리얼 심사대」** · 2026-09-28

## 0. 이 화면이 하는 일은 **하나**다

> **「10초 안에 판단하게 한다」**

<!-- 한바퀴:START -->
대기 **270건**을 한 건씩 보면 — 한 건 30초면 **135분**, 10초로 줄여도 **45분**입니다.
<!-- 한바퀴:END -->

**화면 설계가 그 차이를 만듭니다.**

★**그런데 10초로 줄여도 «한 시간 가까이»입니다.** 그래서 한 가지가 더 필요합니다 —
**같은 이유로 멈춘 건을 «묶어서» 처리하는 길**(§5-2).

그래서 **중요도 순서가 고정**입니다. 아래 순서를 바꾸는 변경은 하지 않습니다.

```
1  왜 멈췄나              ← 이걸 모르면 판단 자체가 불가능하다
2  통과시키면 뭐가 일어나나   ← 버튼 «바로 위». 강의 1강이 짚은 그 문장
3  무엇에 대한 건인가        ← 그림 · 제목 · 작가 · 연도
4  대기열 어디쯤인가         ← 1/33 · 남은 건수 · 진행
```

⛔**장식은 이 넷을 밀어내지 않는 자리에만** 둡니다.

★**1번은 «이유»만이 아니라 «판단할 거리»까지다** (2026-09-29 보탬)
`A3`(민감 어휘)는 낱말만 세고 **맥락은 사람이 봅니다.** 그런데 화면이
「민감어휘가 있다」만 띄워서, 「Battle of Seattle, 1856」인지 「2차대전 때 분실」인지
가리려면 **긴 설명을 다 읽어야** 했습니다 — 10초 목표와 정면으로 어긋납니다.
⇒ `A3` 로 멈춘 건은 **걸린 낱말과 앞뒤 60자**를 「왜 멈췄나」 바로 아래 한 줄로 띄웁니다.
새 요소는 만들지 않았습니다 — 기존 `.lbl` + `.body` + 인용색(`.cite`)입니다.

## 1. ⛔**v1 을 버렸습니다** — 「저번이랑 똑같네」

2026-09-28, 다 만들어 놓고 받은 지적입니다.

> 「디자인적으로 너무 일반적이야. **저번이랑 똑같네.**
>  서비스 느낌도 안 나고, **임팩트 있는 헤드**가 있었으면 좋겠어.」

**맞는 지적이었고, 원인이 이 문서에 적혀 있었습니다.** v1 의 이 자리에는
이렇게 쓰여 있었습니다 —

> ~~서체·색 토큰은 이어받습니다 — **같은 사람의 산출물이라는 표시**입니다.~~

★**이어받은 게 아니라 «안 바꾼» 것이고, 그걸 이 문서에서 정당화까지 했습니다.**
노드9 의 팔레트(`#FCFCFA` 찬 백 + `#A33420` 벽돌)를 그대로 옮겨 놓고
「의도된 일관성」이라 적어 두면, **다음 사람도 그대로 둡니다.**

그리고 **헤드가 아예 없었습니다.** `h1` 이 25px 짜리 한 줄이었습니다 —
그건 제목이지 헤드가 아닙니다.

### ★레퍼런스를 **실제로 열어** 봤습니다

「잘된 사이트처럼」이라는 말은 **재현할 수 없는 지시**라 그대로는 못 씁니다.
⇒ 같은 도메인(미술 아카이브)에서 **우리가 이미 만든 것**을 열었습니다 —
모듈1 메인퀘 **ORIGIN** (`kdt-origin.vercel.app` · `/archive`).
그 `DESIGN-v2.md` 는 8곳을 리서치한 기록이었습니다:
Are.na · Google Arts&Culture · Design Reviewed · Public Domain Review ·
Cosmos · Fonts In Use · Letterform · Cooper Hewitt.

★거기서 읽어 낸 것은 「색이 예쁘다」가 아니라 **«에디토리얼 헤드»의 문법**입니다.

```
① 아이브로우   작은 대문자 · 자간 .2em · 흐린 색
② ★거대 두 줄  같은 크기인데 «무게와 색이 다르다» (900 잉크 / 300 강조)
③ lede        여러 줄 · 흐린 잉크 · max-width 로 줄길이를 묶는다
④ ★메타줄     숫자는 «크고 진하게» · 라벨은 작게 · 세로 구분선
⑤ 섹션마다 «아이브로우 + 헤드 + 부제» 3단이 반복 — 이 반복이 리듬이다
⑥ 가는 가로선으로 구역을 나눈다 (상자로 가두지 않는다)
```

### ⛔그런데 **그대로 베끼면 또 「똑같다」** 입니다

```
ORIGIN   따뜻한 베이지 #f5f2ea + 테라코타 #b4522b   · 종이 «전체»
노드9     찬 백 #FCFCFA + 벽돌 #A33420              · 괘선 도면
★노드10   ★먹빛 «남색» 헤드 #14181F + 미색 작업면 #F7F4EC + ★금빛 황토 #7E5912
```

★**헤드를 «어둡게» 깝니다** — 심사대의 무게입니다. 둘 다와 겹치지 않습니다.

### ★그리고 이건 **브라우즈 사이트가 아니라 작업 도구**입니다

ORIGIN 은 헤드가 화면을 가득 채워도 됩니다 — 한 번 보고 들어가니까요.
⛔**여기는 266건을 처리하는 화면입니다.** 헤드가 매번 화면을 먹으면,
「임팩트」를 얻고 **§0 의 10초를 잃습니다.**

⇒ ★**헤드는 «압축된 에디토리얼»입니다. 크되 낮습니다.**
   실측 — 헤드 전체 **약 300px**, 그 아래 작업 영역이 바로 이어집니다.

| | 노드9 | **노드10 v1** | ★**노드10 v2** |
|---|---|---|---|
| 비유 | 측량 도면 | 결재 데스크 | ★**전시 도록 · 심사대** |
| 하는 일 | 읽는다 | 조작한다 | 조작한다 |
| 머리 | 제목 한 줄 | 제목 한 줄 (25px) | ★**잉크 마스트헤드 · 두 줄 52px** |

| 강조 | 벽돌 | ⛔노드9 그대로 | ★**금빛 황토** (멈춤은 «따로») |

```

paper2     #EFEAE0   가라앉은 면 (조작면)
paper3     #E4DED1   더 가라앉은 면 (막대 홈)

── 잉크 — ★«남색» 먹빛 ────────────────────────────
ink        #14181F   본문 · ★마스트헤드 바탕
ink70      #3D4550   보조 강조
ink50      #636C7A   보조
ink30      #8C95A2   라벨 전용 — ⛔본문에 쓰지 않는다

line       #D5CEBF   괘선
line2      #E7E1D4   약한 괘선

── ★강조와 «멈춤»을 가릅니다 ───────────────────────
gold       #7E5912   ★강조 — 진행 막대 · 초점 링 · 현재 갈래
goldbg     #F2E9D4
stop       #98311A   ★멈춤(위험) «전용» — 멈춘 이유 · 결과 예고

ok         #2B5A42   「자동 처리됨」 한 곳에만

```

### ★v1 은 강조색이 **하나**였습니다 — 그래서 **역할이 섞였습니다**

v1 은 `mark #A33420` **하나**로 「강조」와 「위험」을 다 했습니다.
그러면 진행 막대와 「통과시키면 되돌릴 수 없습니다」가 **같은 색**입니다.
⇒ 위험이 **흔해져서** 위험으로 안 읽힙니다.

```
gold  «여기를 보라»     진행 · 초점 · 현재 위치      ← 자주 나온다
stop  «되돌릴 수 없다»  멈춘 이유 · 결과 예고        ← ★드물게 나온다
```

접근성 규칙 `color-not-only` 대로 **색만으로는 아무것도 말하지 않습니다** —
둘 다 글자가 먼저 말하고, 색은 거들 뿐입니다.

### 서체 — **Pretendard** + **IBM Plex Mono**

★**서체까지 억지로 다르게 하지 않았습니다.** ORIGIN 도 Pretendard 입니다.
한글 본문에 쓸 만한 모던 그로테스크는 선택지가 많지 않고,
**«배치»가 다르면 충분히 다른 물건**이 됩니다. Pretendard 는 **900 까지** 있어
§1 ②의 「같은 크기, 다른 무게」를 **실제로 만들 수 있습니다**(900 ↔ 300).

숫자는 전부 `font-variant-numeric: tabular-nums` (자릿수가 흔들리면 목록이 떨립니다).

### ⛔★한글에 **영문 자간**을 주지 않습니다 — 실제로 틀렸습니다

ORIGIN 에서 베낀 아이브로우 문법을 **한글 라벨에 그대로** 썼습니다:

```
letter-spacing: .18em;  text-transform: uppercase;
```

캡처해 보니 **「나 갈 글」** 로 벌어져 있었습니다.
★**자간을 넓히고 대문자로 바꾸는 것은 «라틴 문자» 문법**입니다
(ORIGIN 의 아이브로우는 전부 영문입니다). 한글엔 대문자가 없고,
낱자가 이미 네모라 자간을 벌리면 **낱말이 풀립니다.**

⇒ 클래스를 **갈랐습니다** —

```
.lbl          한글 라벨   letter-spacing .01em · 무게 700 로 라벨임을 말한다
.lbl.en       영문·기계값  letter-spacing .2em · uppercase · Mono
.eyebrow      영문          위와 같음
```

### ★`edge` 는 **재서** 골랐습니다 — 한 번 틀렸습니다 (v1 기록)

```
#9A9281   paper 와 3.01:1  ✅
          ★조작면과 2.66:1  ⛔  ← 단추 테두리는 «단추 바탕 위»에 있다
#8F8776   paper 3.47:1 · 조작면 3.07:1  ✅
```

**어느 바탕과 재야 하는지를 틀렸습니다.** `redteam.py` 가 잡았습니다.
⇒ 색을 **눈대중으로 고르지 않습니다.** 조건을 적고 **계산해서** 찾습니다.

### ★팔레트를 갈아엎으면 **그 위의 모든 글자를 다시 재야 합니다**

v2 에서 **잉크 바탕**이라는 새 면이 생겼습니다. `redteam.py` 의 대비 목록은
v1 때 **작업면 위 7쌍**만 재고 있었고, 토큰 이름이 바뀌자 **KeyError 로 죽었습니다.**
★그 죽음이 고마운 자리입니다 — 조용히 통과했으면 **헤드 위 5쌍을 영영 안 쟀습니다.**

⇒ 지금은 **14쌍**을 잽니다(헤드 위 5쌍 포함). 실측은 REPORT §정밀검사에 있습니다.

## 3. 갈래를 **색으로 가르지 않는다**

갈래가 넷입니다. 색으로 가르면 빠르지만 **접근성 규칙 `color-not-only`** 를 어깁니다.

```
1순위  ★글자          발행 / 이미지 / 작가 / 카탈로그
2순위   테두리 «모양»   solid / double / dashed / dotted
⛔        색            쓰지 않는다
```

테두리 모양은 **도면의 범례 문법**이고 색맹에게도 갈립니다.
글자가 이미 다 말하므로, 모양은 **거들 뿐**입니다.

### ★마스트헤드는 **한 `st.markdown`** 으로 냅니다

⛔Streamlit 은 markdown 블록마다 **따로 감쌉니다.** 헤드를 여러 번 나눠 부르면
**배경이 끊깁니다.** ⇒ `ui.헤드()` 가 통째로 한 문자열을 냅니다.
전폭으로 까는 것도 그 안에서 — `margin: 0 -50vw; padding: … 50vw`.

★그래서 **수치를 먼저 읽고** 헤드를 찍습니다. v1 은 머리를 먼저 찍고
수치를 나중에 냈는데, 그러면 메타줄이 **비어** 보입니다.

### ★대기열을 **막대**로 그립니다 — 숫자만 있으면 «크기»가 안 읽힙니다

`발행 97 / 작가 92 / 카탈로그 53 / 이미지 9` 는 숫자로 읽으면 그냥 넷입니다.
막대로 그리면 **「이미지는 거의 안 멈춘다」가 한눈에** 들어옵니다.
⛔장식이 아닙니다 — §0 의 「어디쯤인가」를 **한 번에** 답합니다.

### ★읽을 것을 **한 칸**에 모읍니다

처음엔 제목·왜멈췄나는 오른쪽 칸, 「나갈 글」은 전체 폭이었습니다.
**왼쪽 모서리가 두 군데**가 되어 눈이 왔다 갔다 했습니다(캡처로 확인).
⇒ 읽는 것은 **전부 오른쪽 칸**. 그림만 왼쪽.

### ⛔**대기열을 `st.sidebar` 에 두지 않습니다** — 실측 판단

띄워 보니 **사이드바가 DOM 에 아예 안 생겼습니다.**
최소 앱(`st.sidebar` 한 줄)으로 **격리 시험**해도 같았습니다 ⇒ 제 코드 문제가 아닙니다.

★원인이 무엇이든 **대기열이 «사라질 수 있는 자리»에 있으면 안 됩니다** —
채점자 화면에서 대기 건수와 갈래 필터가 통째로 없어집니다.
⇒ **본문 2단**으로 옮겼습니다. 접히지 않습니다.
(부수 효과로 UX 가 나아졌습니다 — 처리하는 동안 대기열이 **계속 보입니다**)

## 5. 조작 — 응답 **넷**, 으뜸 **하나**

```
[발행]  ← 으뜸. 먹색 채움. 「보통 무엇을 하나」를 말한다
[수정 후 발행] [반려] [다시 해설]  ← 대등. 조작면 + 경계
```

★**응답이 둘이면 자동화가 무너집니다**(강의 4강) —
「이 문구만 고쳐서」를 전부 반려하고 사람이 직접 처리하게 됩니다.

- 전부 **최소 높이 44px** (규칙 `touch-target-size`, 실측 46px)
- `focus-visible` 링을 **지운 적이 없습니다** (규칙 `focus-states`)
- ⛔**래퍼 div 로 으뜸을 고르지 않습니다** — Streamlit 이 markdown 블록을 갈라
  `.primary .stButton>button` 이 **안 닿습니다**. 네이티브 `type="primary"` 를 씁니다.

### ★5-2 같은 이유로 멈춘 건을 **묶어서** 처리합니다

⛔**정밀 검사가 잡았습니다** — 대기를 한 건씩 보면 **한 바퀴 44분**입니다.
그런데 `C5`(위키백과가 화가로 확인 못 함)로 멈춘 **92건은 대부분 같은 판단**입니다.

★**강의 4강과 «같은 논리»입니다.**
「이 문구만 고쳐서」를 전부 반려하면 자동화가 무너지듯,
**같은 판단 92건을 하나씩 누르는 것도** 무너짐입니다.

```
묶는 기준   (갈래, 걸린 기준 조합)   — 3건 이상만 묶는다
보여주는 것  ★대표 3건 + 「그리고 N건 더」
안전장치     ① 체크박스로 «전부 처리합니다» 를 먼저 켜야 버튼이 산다
            ② ⛔발행 버튼에만 「★되돌릴 수 없음」을 적는다
            ③ 한 건이 터져도 나머지는 간다. 실패 건수를 «말해 준다»
```

⛔**묶어도 «사람이 봅니다».** 묶음 승인이 「전부 자동」이 되면
이 프로젝트가 막으려는 바로 그것이 됩니다.

### ★목록에서 **골라** 들어갑니다

「다음 →」만 있으면 266번 눌러야 합니다. 드롭다운으로 **바로 갑니다**.

### ★「고쳐서 내보내기」는 **접어 둡니다**

처음엔 「나갈 글」과 textarea 가 **같은 내용을 두 번** 보여 줬습니다.
⇒ 기본은 접힘. 화면이 짧아지고 초점이 안 흩어집니다(규칙 `progressive-disclosure`).

## 8. ⛔Streamlit 에서 **두 번** 밟은 함정

두 번 다 **후손 선택자**였습니다. 같은 병입니다.

```
.dk img          그림에 테두리·폭이 «안 걸렸다»
.primary .stButton>button   으뜸 단추가 «보통 단추»로 보였다
```

★**Streamlit 은 `st.markdown` 블록마다 따로 감쌉니다.**
「같은 도켓 안」처럼 보여도 DOM 에서는 **부모가 다릅니다.**

⇒ **규칙** — 내 클래스 밑으로 타고 내려가는 선택자는
**한 `st.markdown` 호출 안에서 함께 그려질 때만** 씁니다.
`redteam.py` 가 이걸 **검사**합니다.

### ★v2 에서 **세 개 더** 밟았습니다 — 전부 «재서» 찾았습니다

⛔셋 다 **화면을 보고 추측했으면 못 고쳤을** 것들입니다. 실제로 **잽니다.**

**① 아이브로우가 «잘려» 있었습니다**

```
Streamlit 툴바(Deploy · ⋮)가 높이 약 46px 로 «화면 위에 떠» 있다
⇒ margin-top 이 아니라 ★padding-top 62px 로 헤드 «안»을 띄운다
```
margin 으로 밀면 잉크 바탕도 같이 내려가 **위가 미색으로 뜹니다.**

**② 제목 두 줄인데 높이가 195px 이었습니다** (계산은 106px)

```
재 보니  h1 자기 padding  20px + 16px
         ★앵커 링크 span  16px   ← 제목 옆 「🔗」 자리
```
★**「왜 벌어지지?」를 «추측»하지 않고 `getBoundingClientRect` 로 쟀습니다.**
추측했으면 `margin` 을 만지다 끝났을 자리입니다.
⇒ `margin:0!important; padding:0!important` + 앵커 span 숨김.

**③ ★`import ui` 가 «캐시»됩니다**

CSS 를 고치고 다시 캡처했는데 **바이트가 완전히 같았습니다.**
Streamlit 은 스크립트는 다시 돌리지만 **import 된 모듈은 다시 안 읽습니다.**
⇒ ★**CSS 를 고쳤으면 서버를 다시 띄웁니다.**
⛔이걸 모르면 **「고쳤는데 안 바뀌네」 하고 코드를 더 만집니다** — 멀쩡한 코드를.
