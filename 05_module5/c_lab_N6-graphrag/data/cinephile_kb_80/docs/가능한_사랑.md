# 가능한 사랑

분류: 2026년 영화, 개봉 예정 영화, 넷플릭스 오리지널 영화, 대한민국의 드라마 영화, 미국의 드라마 영화, 이창동 감독 영화, 한국어 영화 작품

"가능한 사랑"(영어: Possible Love)은 2026년 개봉 예정인 드라마 영화이다. 이창동이 연출과 공동각본을 맡았다. 제83회(2026년) 베네치아 영화제 황금사자상 경쟁후보작이다.
