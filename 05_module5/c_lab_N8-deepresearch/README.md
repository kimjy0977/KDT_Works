## 한 줄

질문 하나를 던지면 **코디네이터가 목차를 짜고 서브에이전트 넷을 동시에 파견해**
각자 한 절씩 써 오게 하는 딥리서처. 한국 근대사 위키 32건이 코퍼스다.
**정답표 없이** 채점하고, **혼자 하는 것과 붙여** 무엇이 값을 하는지 쟀다.

---

## 여섯 노드

```
① plan       기획   카드(제목+앞 250자)를 보고 목차·역할·시작문서를 정한다
② dispatch   배치   Send 로 팬아웃. 각자에게 «남의 구역»을 들려 보낸다
③ researcher 조사   ★노드 «안»에 루프. 읽고 → 다음 후보 고르고 → 절 원고
④ review     점검   자기신고를 모아 빈 칸을 찾고 재위임. LLM 호출 0회
⑤ compose    종합   절을 이어 붙이고 머리말·맺음말
⑥ evaluate   평가   ★정답표 없이 잰다
                      │
                      └── ④ → ② 재위임 루프 (이중 종료 조건)
```

## 계기판 — 정답표도 판정 모델도 쓰지 않는다

```
근거율      문장 중 «문서명» 붙은 비율      → 깊이·재위임의 계기
★허위 인용  안 읽은 문서를 인용했나         → ★계기가 아니라 «경보». 0이어야 한다
읽고 안 쓴  예산 쓰고 버린 문서             → 배정 «품질»의 계기
최다 편중   인용이 한 문서에 몰렸나         → 배정·구역의 계기
중복률      두 절 이상이 읽은 문서          → 구역 분할의 계기
★격리율     코디가 본 글자 ÷ 팀이 읽은 글자 → 한 자릿수여야 한다
```

전부 **코드로 센다.** 모델 판정이 없어서 **같은 입력에 같은 값**이 나온다.

**단일 실행 실측** — 근거율 75.0% · 허위 인용 0 · 편중 25.0% · 중복률 33.3% ·
★격리율 1.4% · 인용 0곳 절 0개

## ★절제 실험 — 3회 측정

```
조건              근거율        편중          중복률       안쓴   호출   자수
전부 켬(기준선)    72.3%±3.9    27.7%±1.5    33.3%±0.0   1.7    26   1752
배정 끔           73.2%±2.2    30.2%±3.0    ★50.0%      1.7    30   1845
구역 끔           73.5%±4.2    ★44.3%±8.6   42.9%±10.7  1.7    26   1986
역할 끔           75.6%±0.4    29.2%±2.3    33.3%±0.0   2.0    26   1749
재위임 끔         73.8%±2.7    27.1%±2.5    31.7%±2.4   2.0    26   1705
★solo (혼자)      21.7%±1.5    21.4%±5.4     0.0%       ★7.0   14   1448
```

**읽는 법 셋**

1. ★**혼자서는 안 된다** — 근거율 21.7% vs 72.3%(3.3배), 읽고 안 쓴 문서 7건 vs 1.7건.
   **읽어 놓고 보고서에 못 넣는다.** ±1.5 로 안정적이다.
2. ★**근거율로는 장치를 못 가른다** — 조건 사이 최대 차이 3.3%p, 회차 폭 ±4%p.
   **차이가 잡음보다 작다.** 「구역은 낭비를 줄이지 품질을 올리지 않는다」가 그대로 나왔다.
3. **갈리는 것은 둘** — 편중은 «구역»이(27.7→44.3), 중복률은 «배정»이(33.3→50.0).

⚠ **1회 측정이 두 번 속였다** — 배정 끔 근거율이 1회엔 69.0%(낮아 보임), 3회 평균은
73.2%. 역할 끔 편중도 1회 25.0%, 3회 29.2%. **그대로 냈으면 둘 다 틀리게 보고했다.**
