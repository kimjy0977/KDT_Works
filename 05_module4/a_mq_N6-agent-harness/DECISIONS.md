OPEN: 미결정 / CHOSEN: 학생이 선택 / DEFERRED: 학생과 합의하여 후속으로 미룸.
추천은 선택이 아니다. 상태를 바꿀 때 학생 답과 이유를 기록하고 PRD/계약/검증을 함께 갱신한다.

| ID | 결정 | 상태 | 선택과 학생 답 | 이유·영향 |
|---|---|---|---|---|
| D01 | 사용자/업무 | CHOSEN | 학습자 본인. 회의록·체크리스트 정리(자료) + 작은 파이썬 검사 스크립트 수정(코딩). fixture는 `fixtures/notes`·`fixtures/code` | 두 작업이 **읽기→판단→결과** 구조를 공유한다. 실제 개인 자료 대신 같은 상황을 재현한 fixture를 써서 민감정보를 올리지 않는다 |
| D02 | 플랫폼 | CHOSEN | 로컬 CLI | 사용자가 본인이고 이미 터미널을 쓴다. 웹을 고르면 입력·진행 표시·완료/실패 상태·승인 버튼·중복 요청까지 설계 대상이 되는데, 지금 보려는 것은 화면이 아니라 **모델과 도구 사이의 실행 흐름**이다. **감수할 불편** — 여러 파일 결과를 나란히 보기 어렵다. 필요해지면 웹 화면을 별도 설계한다 |
| D03 | 언어 | CHOSEN | Python | 최근 배운 문법으로 **코드를 직접 읽고 검증**할 수 있다. fixture 검사 스크립트도 Python이라 언어가 하나로 끝난다. **감수할 불편** — 타입 검사가 없어 잘못된 모델 응답은 실행 중에 직접 검사해야 한다 |
| D04 | 첫 provider/모델 | CHOSEN | **Ollama · qwen3.5:2b** (로컬) | OpenAI API는 **선불 크레딧이 있어야** 동작하는데 지금 결제 상태가 아니다(구독과 별개). 로컬 모델은 **비용 0 · 키 없음 · 오프라인**이라 바로 시작할 수 있고 `tools` 호출을 지원한다. **감수할 불편** — 2.3B 소형이라 서술 정확도가 낮고(실제로 「오후 3시」를 「저녁」이라 덧붙임) 벤치마크 난문항은 대부분 실패할 것이다. 성능이 필요해지면 D08에서 OpenAI를 추가한다 |
| D05 | 최초 도구/폴더/테스트 범위 | CHOSEN | 도구 **4개** — `list_files` · `read_file` · `write_file`(승인) · `run_command`(승인 · **argv 배열 · 셸 해석 없음**). 작업 폴더는 `work/` 한 곳. 테스트는 `unittest discover -s work` 로 **대상을 고정** | 읽기는 무승인, **쓰기와 실행만** 승인으로 나눈 것이 핵심이다(2강의 「같은 위험이 아니다」). 셸 문자열이 아니라 argv 배열만 받아 `rm -rf *` 같은 확장이 성립하지 않는다. **감수할 불편** — 셸 파이프가 필요한 작업은 못 한다 |
| D06 | 승인 방식 | CHOSEN | **도구 실행 「전」에 내용을 보여 주고 터미널에서 y/n.** 거절하면 **도구 오류로 반환**되어 모델에게 전달되고, 작업은 종료가 아니라 계속된다 | 승인 단위 = **도구 호출 1건**. 거절을 「실패」가 아니라 「오류 결과」로 돌려주므로 모델이 다른 방법을 시도할 수 있다. **실측** — 거절 후 `diff` 로 파일 **바이트 일치** 확인(A04). **감수할 불편** — 호출마다 물어서 긴 작업은 사람이 계속 붙어 있어야 한다 |
| D07 | 세션/저장 방식 | CHOSEN | **파일 저장.** 대화는 `.harness/sessions/{이름}.json`, 실행 기록은 `.harness/runs/{id}.jsonl` 로 **분리**. 재개 시 provider·model·작업 폴더가 다르면 **새 이름을 요구**한다 | 대화(무엇을 말했나)와 실행 기록(무엇을 했나)을 나눠야 «모델 주장 ↔ 실제 실행»을 대조할 수 있다(10강). **실측** — 같은 세션 후속 질문에서 도구 호출 0회로 앞 대화 회수(A08). ⚠ **세션 파일에 fixture 내용이 남는다** → 공개 저장소에 넣지 않는다 |
| D08 | 추가 provider | DEFERRED | OpenAI를 **이번 회차에서 제외**한다 | API 키는 **선불 크레딧**이 있어야 동작하는데 현재 결제 상태가 아니다(ChatGPT 구독과 별개). 어댑터 코드는 제공 구현에 **이미 있어** 크레딧이 생기면 `--provider openai` 한 줄로 전환된다. **미룬 대가** — A10(제공자 간 차이 관찰)을 검증하지 못한다. 결정 ID와 함께 DEFERRED로 남긴다 |
| D09 | 확장 기능 | CHOSEN | **한도와 실행 기록만 넣고** 취소·동시 실행·원격 접속은 **제외**. 한도 = 모델 12단계 · 도구 30회 · 전체 300초 · 도구당 30초 | 한도는 «멈추는 이유를 상태로 남기기» 위한 최소 장치다. **실측** — 모델이 `list_files` 를 반복하자 `status: step_limit` 으로 종료(A06). **감수할 불편** — 긴 작업은 한도에 걸려 미완으로 끝난다. 실제로 벤치마크에서 이 일이 일어났다 |
