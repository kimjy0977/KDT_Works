# experiment-01 — 보고서 본문은 [README.md](README.md) 입니다

과제 안내가 두 곳에서 파일 이름을 다르게 적고 있어, **양쪽 모두에서 찾을 수 있게** 이 파일을 둡니다.

| 안내 위치 | 적힌 이름 |
|---|---|
| **4단계 (제출 지시)** | *"저장소의 **README.md** 에는 가설, 실험 설계, 결과, 다시 검토할 조건을 차례로 적습니다"* |
| 과제 진행 **예시** | *"보고서는 GitHub 저장소의 **experiment-01.md** 로 제출합니다"* |

정식 지시(4단계)를 따라 **본문은 `README.md` 에 있습니다.** 이 파일은 이름표일 뿐입니다.

| | 1차 | 2차 |
