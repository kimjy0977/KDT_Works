### ★확장이 잡아낸 것 — 「만들어 보지 않았으면 몰랐을」 결함 4건

| | 무엇 | 무슨 일이 벌어졌나 |
|---|---|---|
| ① | `extract_json` 이 `[` 를 **`{` 보다 항상 먼저** 찾음 | 모델이 앞에 산문 한 줄만 붙이면 **객체 «안쪽»의 배열**을 답으로 집는다. `status` 가 사라져 `need_input` 이 `result` 로 바뀌고 **100초짜리 웹 검증이 통째로 사라졌다** |
| ② | `normalize` 가 `need_input` 일 때 **본문을 버림** | 모델은 「질문」과 「검증 결과」를 **한 응답에** 담아 보낸다 (CURATOR 의 `action`+`finish` 동시 발생과 같은 종류) |
| ③ | Windows `os.replace` **[WinError 5]** | 목적지를 다른 프로세스가 열고 있으면 원자적 교체가 거부된다. **락은 «한 프로세스 안»에서만 통한다** |
