무엇을 하는 서비스인가

그림 한 점의 제목과 작가만 주면, 에이전트가 공개 데이터에서 사실을 캐고 라이선스를 판정하고 중복 등재를 확인한 뒤 한국어 해설 초안까지 만들어 사람의 승인 앞에 갖다 놓습니다.

승인 없이는 아무것도 등재되지 않습니다. 등재 도구는 모델에게 보여 주지도 않고, 런타임이 승인 상태를 검사합니다.

★무엇이 «나오는가» — 정확히

이 서비스가 만들어 내는 것은 등재 레코드 JSON 한 건입니다. 공개 아카이브에 «자동으로 써 넣지 않습니다». 승인하면 레코드가 확정되고, ④ 결과 탭에서 내려받아 아카이브에 넣는 것은 사람이 합니다.

⛔일부러 그렇게 했습니다. 이 페이지는 «공개 배포본»입니다. 여기에 실제 아카이브 쓰기 권한을 넣으면 링크를 아는 누구나 남의 아카이브에 쓸 수 있게 됩니다. 되돌리기 어려운 쓰기는 공개 화면 뒤에 두지 않습니다.
