## D-01. 구현 언어 — **Python**

| | |
|---|---|
| 버린 것 | TypeScript(Node) · Rust |
| **왜** | ①글자 렌더링에 **Pillow** 가 이미 있다 ②웹 서버를 **표준 라이브러리 `http.server`** 로 짤 수 있어 `npm install` 없이 돈다 ③채점자가 `python app.py` 한 줄로 띄운다 |
| 대가 | 타입 검사가 없다 → 자체 시험으로 메운다 |

## D-02. 실행 엔진 — **Claude CLI** 하나만

| | |
|---|---|
| 버린 것 | Claude Agent SDK · OpenCode CLI |
| **왜** | PRD 가 *「전부 구현하는 것은 필수 아님」* 이라 했고, **실제로 인증이 확인된 것**이 이것이다. SDK 는 파이썬 패키지 설치가 더 필요하고, OpenCode 는 인증을 확인하지 않았다 |
| 이어가기 | `--resume <session_id>` — 4강 표 그대로 |
| ⚠ 대가 | 호출당 **캐시 생성 47K 토큰**이 잡힌다(Claude Code 자체 프롬프트). **호출 수를 아껴야 한다** → 조사는 «한 번에 후보 전부», 심층검증은 «선택한 것만» |

## D-03. ★이미지 — **Antigravity 가 없어서 «PD·CC0 경로»로 간다**

| | |
|---|---|
| PRD 의 기본안 | Antigravity CLI(`agy`) 의 내장 이미지 도구로 **생성** |
| **실제** | **`agy` 가 설치돼 있지 않다.** 설치·로그인·권한을 확인할 수 없었다 |
| 고른 길 | PRD 가 명시적으로 허용한 **「CC0·공개 도메인 또는 이용 조건에 맞는 스톡」** 경로 — **Wikimedia Commons** 에서 라이선스를 확인하고 가져온다 |
| **왜 이게 맞는가** | 내 도메인이 **퍼블릭 도메인 명화 아카이브**다. 상위 폴더의 CURATOR 가 이미 `commons_file` 로 **라이선스를 판정하고 출처를 기록**한다. 같은 도구를 그대로 쓴다 |
| ⛔ **하지 않은 것** | **`agy image generate` 같은 «확인하지 않은 명령»을 만들어 성공한 척하지 않았다.** PRD 5절이 금지한 그것이다 |
| 기록 | 모든 이미지에 **출처 URL · 라이선스 · 작가 · 가져온 날짜**를 남긴다. 생성 이미지가 아니므로 «생성 도구·프롬프트» 칸은 «해당 없음»으로 둔다 |
| 미완료 | **AI 이미지 생성 경로는 «미확인»이다.** `README.md` 의 미검증 목록에 그대로 적었다 |

## D-04. 상태 저장 — **프로젝트별 폴더 + JSON**

| | |
|---|---|
| 버린 것 | SQLite · 인메모리 |
| **왜** | ①4강이 *「서버를 재시작하면 메모리에서 기다리던 콜백은 사라진다」* 고 경고했다 — **디스크에 있어야 한다** ②PRD 가 *「작업별 디렉터리를 분리한다」* 고 했다 ③채점자가 **`data/<projectId>/state.json` 을 그냥 열어 볼 수 있다** |
| 대가 | 동시 쓰기 보호가 약하다 → 쓰기를 **한 곳(`store.py`)으로 모으고 원자적 교체**(temp → replace)로 막는다 |

## D-05. 카드 크기 — **1080×1350** (세로 4:5)

인스타그램 캐러셀의 세로 최대 비율이고, PRD 가 제시한 두 값 중 **글자가 더 들어가는** 쪽이다.
2강에서 본 형식들이 대부분 «한 장에 메시지 하나 + 짧은 본문»이라 세로가 유리하다.

## D-06. ★글자는 **이미지와 «완전히 분리»**

| | |
|---|---|
| 어떻게 | 배경 이미지는 그대로 두고 **Pillow 로 텍스트 레이어를 따로 그린다** |
| **왜** | 5강 — *「그래야 맞춤법과 사실관계를 고칠 때 이미지를 다시 생성하지 않아도 된다」* |
| 확인 | **텍스트만 고쳤을 때 배경 파일의 해시가 그대로인지**를 검사한다 (참고 구현 v5.1.5 는 이걸 못 한다고 3강이 밝혔다) |

## D-07. 포트 **8765**, `127.0.0.1` 에만 바인딩

PRD 지정값. **외부에 열지 않는다** — 이건 실습용 로컬 앱이다.

## D-08. 엔진 결과 정규화 — `progress` / `need_input` / `result` / `error`

PRD 가 정한 규약. **이 앱이 정하는 것이지 CLI 에 내장된 공통 규격이 아니다**(PRD 원문 그대로).
CLI 는 `need_input` 을 돌려주고 **프로세스가 끝난다.** 웹앱은 **완료로 표시하지 않고 `waiting_for_user`** 로 남긴다.

## D-09. 중복 요청 — `requestId` 로 막는다

PRD: *「같은 ID·같은 입력은 저장한 결과를 반환하고 같은 ID·다른 입력은 충돌로 거절한다」*
답변은 **질문 ID + version** 을 확인해 **한 번만** 반영하고 **오래된 화면의 답변은 거절**한다.

## D-10. 셸 주입 방지 — 인자 «배열»로만 실행

PRD: *「사용자가 입력한 주제를 셸 명령 문자열에 이어 붙이지 않는다」*
`subprocess.run([...], shell=False)` 만 쓴다. 프롬프트는 **stdin 또는 인자 배열**로 넘긴다.
