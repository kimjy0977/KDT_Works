## ★막힌 것과 어떻게 풀었나

만드는 동안 **다섯 번 막혔습니다.** 전부 «성공한 척하지 않고» 원인을 찾아 고쳤습니다.

> ⚠**그리고 확장(신화 모드)을 붙이다 «여기 있던» 버그를 셋 더 찾았습니다** —
> `extract_json` 이 모델의 답을 통째로 버린 것 · `normalize` 가 `need_input` 의 본문을 버린 것 ·
> Windows 에서 `os.replace` 가 상태 저장을 터뜨린 것. **셋 다 오류를 안 내고 조용히 틀렸습니다.**
> 자세한 것은 **[MYTH-MODE.md §고치는 동안 찾은 결함 셋](MYTH-MODE.md)**.
> ★**확장을 만들지 않았으면 못 찾았을 것들입니다.**

### ① `claude.CMD` 가 여러 줄 인자를 잘라 먹었다 — 가장 오래 걸린 것

모델이 **대화체로** 답했습니다. *"아직 구체적인 요청이 없어서요…"*

원인: npm 이 만든 **`claude.CMD` 배치 셈**을 거치며 cmd.exe 가 **여러 줄 인자를 첫 줄에서 자릅니다.**
784자 프롬프트 중 첫 줄만 갔고, 뒤에 붙인 `--output-format json` 까지 **통째로 무시**됐습니다.

> ⚠ **한 줄짜리 시험은 통과했습니다.** 그래서 한참 못 알아챘습니다.
> → **프롬프트를 `stdin` 으로** 넘깁니다. 인자 배열만 쓰는 원칙(셸 주입 방지)은 그대로입니다.

### ② 엔진이 «레포의 맥락»을 읽었다

작업 디렉터리가 저장소 안이라 Claude CLI 가 `CLAUDE.md` 와 git 이력을 읽고
*"최근 커밋을 보니 MQ4 큐레이션 평가…"* 라고 답했습니다. **내 프롬프트가 프로젝트 컨텍스트에 묻혔습니다.**
→ PRD 가 말한 대로 **작업별 디렉터리를 분리**했습니다(`data/<projectId>/engine/`).

### ③ 서버가 «세 개» 떠 있었다

고친 코드가 반영이 안 됐습니다. `pkill` 이 Windows 에서 안 먹어 **옛 서버가 계속 응답**했습니다.
→ 포트를 잡고 있는 PID 를 직접 찾아 종료합니다.

### ④ 화면의 선택지 버튼이 안 눌렸다

에이전트가 만든 선택지에 **작은따옴표**가 들어 있었습니다 — `AI 입문자 — '소버린 AI가 뭐고…'부터`.
인라인 `onclick="answer('…')"` 의 JS 문자열이 통째로 깨졌습니다.
→ **모델이 만든 문자열을 코드에 끼워 넣지 않습니다.** `data-` 속성 + 이벤트로 «값을 전달»합니다.

### ⑤ 배경 이미지가 5장 다 실패했다

두 가지가 겹쳤습니다.
- 모델이 낸 **10단어짜리 장면 묘사**로는 Commons 가 **0건**을 줍니다 → **질의를 단계적으로 줄여** 재시도
- 찾은 파일이 **SVG** 라 Pillow 가 못 엽니다 → **`iiurlwidth` 로 래스터 썸네일**을 받습니다

→ 고친 뒤 **5/5 확보.**
